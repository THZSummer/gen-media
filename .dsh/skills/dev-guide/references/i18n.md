# 双语规范（i18n）

> 返回 [SKILL.md](../SKILL.md)

## 1. 命名与切换行

| 约定 | 内容 |
|------|------|
| 命名 | `README.md` ↔ `README.en.md`；`period-01/README.md` ↔ `period-01/README.en.md` |
| 中文侧 | 首行（H1 之后）：`> 🌐 语言：**中文** ｜ [English](X.en.md)` |
| 英文侧 | 首行（H1 之后）：`> 🌐 Language: **English** | [中文](X.md)` |
| 排除 | `.dsh/skills/`、`.agents/skills/`、`.agents/skills/` —— 技能文档只有中文 |

有 YAML frontmatter 的文件，切换行插在 frontmatter 之后、H1 之下。切换行由 `i18n.py switch` 幂等写入，手写时格式照抄即可。

## 2. 翻什么、不翻什么

| 要翻译 | 逐字保留 |
|--------|----------|
| 散文、标题、表头、列表项、图注 | 命令、路径、文件名、URL、模型 ID、参数名、变量名 |
| **代码块里的说明性注释**：目录树注释、bash `#` 注释、ASCII 示意图标签 | prompt 原文（中英皆然）、seed / sha256 / prompt_id、样例字符串 |
| 表格里的说明性文字 | 作者名（如「小七」）、镜头名（shot 名） |

> 边界踩过坑：把代码块"整体不翻"会让英文读者看不懂目录树；把注释也翻掉才算合格。

## 3. 流水线命令

```sh
python3 tools/i18n.py status          # 覆盖率：还有哪些 md 缺英文版（按目录汇总）
python3 tools/i18n.py switch          # 幂等写入/更新两侧语言切换行
python3 tools/i18n.py links           # 英文版内链改指 .en.md（语言切换行不动）
python3 tools/i18n.py check           # 体检：缺件 / 疑似未翻译 / 英文版断链
python3 tools/i18n.py check --strict  # 有问题时退出码 1（可挂 CI）
python3 tools/i18n.py check --ratio 0.6   # 调整"疑似未翻译"阈值
```

## 4. 判据

- **疑似未翻译** = 英文版**围栏块外**汉字数 ÷ 中文版同口径 > `--ratio`（默认 0.5）。
  用"围栏块外"是因为 prompt 存档类文件正文中文都在代码块内：全文口径会把 `prompts-all` 误报成 91%，围栏外口径只有 19 字（原文 1472 字）。
- **预期断链** = 指向 `work/`、`out/r*/` 的链接（本地保留、不入库）。`check` 单独计数，不计入问题。

## 5. 常见错误

| 症状 | 原因 | 处理 |
|------|------|------|
| 英文版 `[中文](…)` 指向自己 | `links` 误改了语言切换行 | 重跑 `switch`；该规则已修（切换行不重定向） |
| 新增中文文档后 `check` 报缺英文版 | 忘了写 `X.en.md` | 补英文版，或确认它属于技能目录（应被排除） |
| 英文版断链 | 目标只有中文版、或路径写错 | 目标有英文版就写 `.en.md`；没有就指向中文版 |
