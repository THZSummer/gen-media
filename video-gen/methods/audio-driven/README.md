# 音频驱动视频（Audio-Driven）

> 🌐 语言：**中文** ｜ [English](README.en.md)

> 输入：参考音频 + prompt。输出：画面节奏跟随音频（节拍/节奏）的视频。
> 返回[方法总览](../README.md) ｜ 适用模型：Seedance 系列（支持 ref_audio 的版本）

---

## 一、主题定位

音频驱动是**让画面跟着声音走**的路径：你有一段音乐/节拍音频，想让视频的镜头切换、蒙太奇节奏与音频同步。本质是"音频节奏 -> 画面节奏"。

### 何时选音频驱动

- 卡点视频（踩鼓点切镜头）
- MV、广告片配乐画面
- 节拍切换的城市/产品蒙太奇
- 想要"音乐高潮时画面也高潮"的同步感

### 何时不选

- 想要视频自带配音 -> 用 `--generate-audio`（模型生成音频，非音频驱动）。✅ 仅 `doubao-seedance-1-5-pro` / `doubao-seedance-2-0`（260128，实测 2026-08-01）支持；⛔ 2.0-fast / mini output 仅 video 无音频
- 没有特定音频、只需画面 -> [text-to-video](../text-to-video/README.md)
- 想复刻视频运动 -> [reference-video](../reference-video/README.md)

> ⚠️ 区分两个概念：
> - **音频驱动**：你提供音频，画面跟随音频节奏（本主题）
> - **生成音频**：模型为视频生成配音/BGM（`--generate-audio`，不需要你提供音频）。✅ 1.5-pro / 2.0（260128）支持；⛔ 2.0-fast / mini output 仅 video

## 二、能力映射

| 控制维度 | 音频驱动下的手段 |
|----------|----------------|
| 节奏 | 参考音频强约束 |
| 画面内容 | prompt 描述 |
| 镜头切换 | 随节拍自动切换（蒙太奇） |
| 风格 | prompt 风格描述 |

### 工作机制

```
参考音频的节拍/能量变化 ──► 视频的镜头切换/节奏
prompt 描述的画面/风格   ──► 视频的内容
```

模型从音频提取节奏特征，把节拍点映射成镜头切换点，形成"踩点"效果。

---

## 三、音频选择策略

### 好的参考音频

| 特征 | 说明 |
|------|------|
| 节拍明确 | 鼓点/重音清晰，强弱分明 |
| 节奏稳定 | BPM 稳定，便于切镜 |
| 时长匹配 | 与目标视频时长接近 |
| 动态范围 | 有起伏，高潮段落明显 |

### 坏的参考音频

- 纯环境音/白噪声（无节拍可提取）
- 节奏混乱、自由拍
- 过长未裁剪（关键段被稀释）

### 自制节拍音频

没有现成音乐时，可用任意 DAW/节拍生成器导出一串清晰鼓点，效果往往比复杂音乐更可控。

---

## 四、Prompt 策略

音频驱动的 prompt 重点在**描述画面内容和切换风格**，节奏交给音频。

### 推荐结构

```
[画面主题/场景] + [蒙太奇/切换风格] + [随节拍切换的元素]
```

**示例**：
> 随节拍切换的城市夜景蒙太奇，霓虹灯、车流、行人特写交替出现，赛博朋克色调

### 要点

- **点明"随节拍/踩点"**：让模型明确要做节奏切换
- **给可切换的元素清单**：蒙太奇需要多个画面元素轮换
- **不要写具体时间点**：节奏由音频决定，prompt 写"第2秒切镜头"无效
- **风格统一**：所有切换元素保持统一调色/风格

---

## 五、参数选型

| 参数 | 音频驱动建议 | 说明 |
|------|-------------|------|
| `--input` | `ref:@beat.mp3` | 用 `ref:` 前缀明确是参考音频 |
| `--ratio` | 按发布渠道 | 竖屏卡点常用 `9:16` |
| `--duration` | 与音频关键段时长接近 | |
| `--generate-audio` | 一般不用 | 避免与参考音频冲突；如需最终带声，后期合成 |
| `--draft` | 试踩点效果时用 | |

> 音频作为 `--input` 时，按扩展名（`.mp3`/`.wav` 等）自动分流到 ref_audio 通道。视频任务里第一张图才是首帧，音频不会占首帧位。

## 六、命令模板

```bash
VER=$(arkcli models get doubao-seedance-2-0 --transform 'primary_version' | tr -d '"')
MODEL="doubao-seedance-2-0-${VER:-260128}"

# 1) 节拍蒙太奇
arkcli +gen --model "$MODEL" \
  --input ref:@beat.mp3 --ratio 9:16 \
  "随节拍切换的城市夜景蒙太奇，霓虹、车流、行人特写交替，赛博朋克色调" --open

# 2) 配乐画面同步
arkcli +gen --model "$MODEL" \
  --input ref:@bgm.mp3 --ratio 16:9 --duration 5 \
  "产品在不同场景中流转，画面随音乐起伏推进，影棚光" --open

# 3) 音频 + 首帧图组合（首帧图 + 参考音频）
arkcli +gen --model "$MODEL" \
  --input @first.jpg --input ref:@beat.mp3 \
  "从首帧开始，随节拍切到不同角度的特写" --open
```

## 七、踩坑点

| 现象 | 原因 | 处理 |
|------|------|------|
| 没有踩点感 | 音频无清晰节拍 | 换鼓点明确的音频 |
| 切镜混乱 | prompt 元素太少/太杂 | 给 3-5 个明确可切换元素 |
| 音频被当首帧 | 误用普通 `--input` | 音频用 `ref:` 前缀 |
| 时长不匹配 | 音频长但 duration 短 | duration 对齐音频关键段 |
| 最终无声 | 视频默认不带音频 | 后期把参考音频合成回视频 |
| 生成音频冲突 | 同时 `--generate-audio` 与 ref 音频 | 二选一，音频驱动场景关掉 generate-audio |

---

## 八、检查清单

- [ ] 音频节拍清晰、节奏稳定
- [ ] `--input ref:@audio.mp3` 用 `ref:` 前缀
- [ ] prompt 点明"随节拍/踩点"
- [ ] prompt 提供 3-5 个可切换画面元素
- [ ] `--duration` 与音频关键段对齐
- [ ] 不要同时开 `--generate-audio`
- [ ] 最终带声走后期合成
