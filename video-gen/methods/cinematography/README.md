# 镜头运镜与分镜（Cinematography）

> 控制镜头运动、构图、分镜设计的横切主题，适用于所有输入路径（T2V/I2V/R2V/音频驱动）。
> 返回[方法总览](../README.md)

---

## 一、主题定位

镜头语言是把"会动的图"变成"有叙事的视频"的关键。本主题不限定输入路径，专注**如何让镜头按你的意图运动**，以及如何用分镜组织多镜头叙事。

### 适用场景

- 需要专业运镜（推/拉/摇/移/跟/环绕）
- 多镜头叙事（远景->中景->特写）
- 避免"模型自作主张乱运镜"
- 为 [long-video-chain](../long-video-chain/README.md) 设计分镜

---

## 二、运镜词汇表

在 prompt 里用这些词描述镜头运动，模型识别度较高：

| 运镜 | 描述词 | 效果 |
|------|--------|------|
| 推 | 镜头推近 / dolly in / 推进 | 向主体靠近，强调 |
| 拉 | 镜头拉远 / dolly out / 拉远 | 远离主体，交代环境 |
| 摇 | 镜头向左/右摇 / pan | 水平转动，扫视 |
| 移 | 镜头平移 / tracking | 跟随主体移动 |
| 跟 | 跟拍 / follow | 跟随主体运动 |
| 环绕 | 镜头环绕 / orbit | 围绕主体转圈 |
| 升降 | 镜头升起/下降 / crane | 垂直运镜 |
| 固定 | 固定镜头 / static | 镜头不动，主体动 |
| 航拍 | 航拍 / aerial | 俯视大范围 |
| 延时 | 延时摄影 / timelapse | 时间压缩 |

### 构图与景别词

- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 大特写
- 角度：平视 / 仰视 / 俯视 / 鸟瞰
- 景深：浅景深 / 深景深
- 焦段：广角 / 长焦 / 微距

## 三、两条控制路径

### 路径 A：prompt 描述运镜（默认）

在 prompt 里写明镜头运动，模型据此生成。**最常用**。

```
"镜头缓慢拉远，主体居中保持不动，背景云层流动"
"镜头环绕产品旋转一圈，影棚光"
"航拍视角，从高空俯冲向城市"
```

要点：
- 一次只描述**一种主运镜**，多运镜混写会冲突
- 运镜 + 速度修饰（缓慢/快速/匀速）更可控
- 配合景别/角度词增强表达

### 路径 B：`--camera-fixed` 固定镜头

当你要**静态构图、主体动而镜头不动**时，用 `--camera-fixed` 锁死虚拟镜头，防止模型脑补运镜。

```bash
arkcli +gen --model "$MODEL" --camera-fixed \
  "主体在画面中央活动，背景固定" --open
```

适用：
- 产品展示（产品动、镜头不动）
- 固定机位记录
- 避免意外运镜破坏构图

> 反例：想要运镜时却加 `--camera-fixed` -> 镜头锁死，运镜失效。两者互斥，按需选一。

## 四、分镜设计（多镜头叙事）

单条视频时长有限（默认 5s），叙事靠**多条分镜拼接**。设计分镜是 [long-video-chain](../long-video-chain/README.md) 的前置规划。

### 分镜表模板

| 镜号 | 景别 | 运镜 | 内容 | 时长 | 衔接 |
|------|------|------|------|------|------|
| 1 | 远景 | 航拍推近 | 城市全貌 | 5s | 切 |
| 2 | 中景 | 跟拍 | 主角走入街道 | 5s | 续接(末帧->首帧) |
| 3 | 特写 | 固定 | 主角表情 | 5s | 切 |

### 衔接方式

| 方式 | 说明 | 实现 |
|------|------|------|
| 硬切 | 直接拼接，节奏快 | 后期剪辑，或独立生成 |
| 续接 | 上一条末帧作下一条首帧，连续 | `--return-last-frame` 链式 |
| 动作衔接 | 上一条动作接下一条 | prompt 描述动作连续 |

### 单镜头原则

每条视频**只讲一个运镜+一个主体动作**，别塞太多。复杂叙事拆成多条分镜，在 [long-video-chain](../long-video-chain/README.md) 串联。

---

## 五、参数选型

| 参数 | 运镜场景建议 | 说明 |
|------|-------------|------|
| `--camera-fixed` | 静态构图用 | 锁镜头 |
| `--ratio` | 横屏叙事 `16:9`，竖屏 `9:16` | |
| `--duration` | 单镜头 5s 起 | 复杂运镜可适当加长 |
| `--return-last-frame` | 续接用 | 拿末帧给下一条 |
| `--seed` | 分镜一致性 | 同场景多镜头固定种子保持画风 |

## 六、命令模板

```bash
VER=$(arkcli models get doubao-seedance-2-0 --transform 'primary_version' | tr -d '"')
MODEL="doubao-seedance-2-0-${VER:-260128}"

# A) prompt 运镜：环绕
arkcli +gen --model "$MODEL" --ratio 16:9 \
  "镜头环绕一双运动鞋缓慢旋转一圈，影棚光，纯黑背景，浅景深" --open

# B) 固定镜头：主体动镜头不动
arkcli +gen --model "$MODEL" --camera-fixed \
  "咖啡杯在画面中央，热气升起，背景虚化固定" --open

# C) 航拍推近
arkcli +gen --model "$MODEL" \
  "航拍视角，从高空俯冲向雪山村庄，云层从镜头旁掠过" --open

# D) 续接分镜：拿末帧作下一条首帧
arkcli +gen --model "$MODEL" --return-last-frame \
  --input @shot1.jpg "镜头向右摇，展现街道" --open
```

## 七、踩坑点

| 现象 | 原因 | 处理 |
|------|------|------|
| 运镜乱/跳 | prompt 多运镜混写 | 一次只写一种主运镜 |
| 想运镜却不动 | 误加 `--camera-fixed` | 运镜场景去掉该 flag |
| 镜头眩晕 | 运镜过快/过多 | 加"缓慢/匀速"，单镜头单运镜 |
| 多镜头画风不一 | 种子随机 | 同场景固定 `--seed` |
| 续接跳变 | 末帧与下条首帧不符 | 用 `--return-last-frame` 真末帧，别另选图 |

## 八、检查清单

- [ ] prompt 只描述一种主运镜 + 速度修饰
- [ ] 静态构图才用 `--camera-fixed`，运镜场景不用
- [ ] 多镜头叙事先列分镜表
- [ ] 同场景多镜头固定 `--seed` 保画风一致
- [ ] 续接用 `--return-last-frame` 拿真末帧
- [ ] 单镜头单运镜单主体动作
