# 参考视频生成（Reference-to-Video, R2V）

> 输入：一段参考视频 + prompt。输出：保持参考视频运动轨迹、按 prompt 替换内容的新视频。
> 返回[方法总览](../README.md) ｜ 适用模型：`doubao-seedance-2-0-r2v`（R2V 专用）

---

## 一、主题定位

参考视频是**借运动、换内容**的路径：你有一段满意运镜/动作的现成视频（自己拍的、素材库的），想让模型**复刻它的运动轨迹**，但把主角/场景换成你想要的。本质是"运动迁移 + 内容替换"。

### 何时选 R2V

- 看中某段视频的运镜/节奏，想套到自己主体上
- 动作复杂、用 prompt 难以精确描述（舞蹈、武术、复杂手势）
- 需要"像那段视频一样的运动感"
- 跨主体迁移：把人的动作套到机器人/卡通角色

### 何时不选

- 只想静图动起来 -> [image-to-video](../image-to-video/README.md)
- 只想从文字试 -> [text-to-video](../text-to-video/README.md)
- 想跟着音乐节奏走 -> [audio-driven](../audio-driven/README.md)

## 二、能力映射

| 控制维度 | R2V 下的手段 |
|----------|-------------|
| 运动轨迹 | 参考视频强约束（核心价值） |
| 主体/内容 | prompt 描述要替换成的样子 |
| 风格 | prompt 风格描述 |
| 镜头 | 跟随参考视频，`--camera-fixed` 一般不用 |

### 核心价值

```
参考视频的运动 ──保留──►  新视频的运动
参考视频的内容 ──替换──►  prompt 描述的内容
```

模型学习的是参考视频的**运动场**（怎么动），而非像素（长什么样）。

---

## 三、参考视频选择策略

参考视频的质量直接决定 R2V 成败。

### 好的参考视频

| 特征 | 说明 |
|------|------|
| 运动清晰 | 主体运动明确，别是大段静止 |
| 主体单一 | 一个明确主体，多主体容易迁移错乱 |
| 光照稳定 | 忽明忽暗会干扰运动提取 |
| 时长适中 | 与目标时长接近，过长截取关键段 |
| 无遮挡 | 主体不被频繁遮挡 |

### 坏的参考视频

- 镜头剧烈抖动（运动场噪声大）
- 快速剪辑拼接（运动不连续）
- 主体过小或过度遮挡
- 大量文字/UI 叠加

### 自制参考视频

没有现成素材时，可以**自己拍/用 T2V 先生成一段运动满意的视频**当参考：

```
1) T2V 生成一段运动满意但内容一般的视频
2) 用它当 R2V 参考视频，替换成目标内容
```

---

## 四、Prompt 策略

R2V 的 prompt 重点在**描述目标内容/主体/风格**，运动交给参考视频。

### 推荐结构

```
[新主体描述] + [新场景/环境] + [风格]
```

**示例**：
> 参考视频保持运动不变，主角替换为一个银色机器人，赛博朋克城市背景，金属质感，电影色调

### 要点

- **明确"保持参考运动"**：prompt 里点明"保持参考视频的运动轨迹/节奏"
- **新主体要具体**：颜色、材质、服饰，避免模糊
- **不要描述运动**：运动由参考视频给，prompt 写运动会和参考冲突
- **风格统一**：风格描述要覆盖主体和场景，否则割裂

---

## 五、参数选型

| 参数 | R2V 建议 | 说明 |
|------|----------|------|
| `--input` | `ref:@reference.mp4` | 用 `ref:` 前缀明确是参考视频 |
| `--ratio` | 与参考视频比例一致 | 避免运动场错位 |
| `--resolution` | 按需，定稿 1080p | |
| `--duration` | 与参考视频时长接近 | 运动对齐更自然 |
| `--draft` | 试迁移效果时用 | |

> ⚠️ R2V 专用模型（`...-r2v-...`）走参考视频通道；普通 seedance 模型传视频作 `--input` 也可能被识别为参考视频，但**优先用 r2v 专用模型**，迁移质量更稳。

## 六、命令模板

```bash
# R2V 专用模型补全
VER=$(arkcli models get doubao-seedance-2-0-r2v --transform 'primary_version' | tr -d '"')
R2V="doubao-seedance-2-0-r2v-${VER:-260128}"

# 1) 标准参考视频生成
arkcli +gen --model "$R2V" \
  --input ref:@reference.mp4 --ratio 16:9 \
  "保持参考视频的运动轨迹，主角替换为银色机器人，赛博朋克城市，金属质感" --open

# 2) 风格迁移（保留运动换画风）
arkcli +gen --model "$R2V" \
  --input ref:@dance.mp4 \
  "保持舞蹈动作，角色改为水彩画风格，柔和水墨晕染" --open

# 3) 自制参考：先 T2V 再 R2V
arkcli +gen --model "$MODEL" "一段镜头环绕产品旋转的运动" --wait --open
# (得到 ref.mp4)
arkcli +gen --model "$R2V" --input ref:@ref.mp4 \
  "保持环绕运动，产品替换为新型耳机，纯白背景，影棚光" --open
```

## 七、踩坑点

| 现象 | 原因 | 处理 |
|------|------|------|
| 运动没迁移上 | 用了非 r2v 模型 / 参考视频质量差 | 优先 `...-r2v-...` 模型，换清晰参考视频 |
| 主体错乱 | 参考视频多主体 | 裁剪到单主体段 |
| 运动错位 | `--ratio` 与参考不一致 | 比例对齐 |
| prompt 写运动冲突 | 描述运动干扰参考 | prompt 只写内容，删除运动描述 |
| 视频扩展名不被识别 | 非标准扩展名 | 用 `.mp4` 等标准格式 |
| 内容被审核 | 新主体/场景违规 | 见 [content-safety](../content-safety/README.md) |

---

## 八、检查清单

- [ ] 使用 R2V 专用模型（`...-r2v-...`）
- [ ] 参考视频运动清晰、主体单一、光照稳定
- [ ] `--input ref:@video.mp4` 用 `ref:` 前缀
- [ ] `--ratio` 与参考视频一致
- [ ] prompt 只描述新内容/风格，不写运动
- [ ] prompt 点明"保持参考运动"
- [ ] 无现成参考时，用 T2V 自制一段
