# 来杯好茶摇一摇（tea-shake-dance）

> 返回[项目索引](../README.md) ｜ 技术方法见 [../../methods/](../../methods/README.md)

艺术舞蹈短片：以「摇一摇」为动作母题，把茶文化（茶汤、茶香、冲泡姿态）跳成一支现代舞。

## 一、项目背景

- **项目名**：tea-shake-dance（来杯好茶摇一摇）
- **类型**：艺术舞蹈视频
- **目标**：一支 30s 左右的现代舞短片，把「泡茶/摇茶」的动作姿态抽象成舞蹈语汇——茶汤的旋涡、茶香氤氲、杯盏的摇动，成为舞者的身体语言。走偏概念/氛围的短视频，不做剧情叙事。
- **发布渠道**：短视频平台（抖音/视频号/B站竖屏，或小红书横屏）
- **交付时间**：待定（先定向验证方向）

> 💥 爆点三要素：① 前 3 秒悬念钩子（镜 1 清纯面部特写）；② 极致反差（镜 2 同一张脸狂暴灭世）；③ 闭环反转（镜 7 梦醒睁眼，观众恍然大悟"原来是梦"）。

### 4.3 分镜图（关键帧）生成与审核

**为什么先出图**：直接 T2V 出视频，画面/服装/场景/构图是否符合预期要到生成后才能看，返工成本高（一次 5s 视频 ≈ 若干 token + 时间）。先用 seedream 出**每镜关键帧（分镜图）**，人工审核构图、风格、主体一致性，确认后再 I2V 动起来——画面不符合预期时只重出图，成本低一个量级。

**生成命令**（模型 `doubao-seedream-5-0-lite`，默认 agent-plan profile）：

```bash
MODEL="doubao-seedream-5-0-lite"
# 镜号 N 的分镜图：prompt = 通用锚点 + 该镜静止姿态描述（取 §4.2 每镜"姿态/手位"定格）
# ⚠️ 图片比例用 --size（像素）不用 --ratio（--ratio 仅视频有效，忽略后默认 2048x2048 正方形）
arkcli +gen --model "$MODEL" --size "2560x1440" --output-format jpeg \
  "<通用视觉锚点> <该镜关键姿态描述，如：舞者双手捧盏低头凝神，茶烟升腾，淡雅茶室，青绿水墨色调，留白氛围>" \
  --save-to out/storyboard/
```

> 提示：分镜图取的是**该镜最有代表性的静态瞬间**（如镜 1 的"甩茶撕裂星河"、镜 4 的"星系炸裂"），不追求动态过程；动态交给 I2V 补。
> 📦 版本归档（全部保留作参考）：`v1-classic/`（平静茶室）/ `v1.5-cyber-ink/`（赛博水墨）/ `v2-astro/`（时空主宰）/ `v3-spec-iterations/`（规格书迭代版）/ 当前正式版 `shot1-7_final.jpg`（v4 梦境闭环全 7 镜）。
> 竖屏版分镜图用 `--size "1440x2560"`（9:16）单独出一版（比例影响构图，不能横图硬裁）。

**审核清单**（每镜过图时逐项核对，不通过则重出）：

- [ ] 舞者形象一致：高马尾发丝飞散、露肩水墨渐变长裙、东方女性、鲜活表情（6 镜同款）
- [ ] 背景一致：现代霓虹茶馆夜景（玻璃幕墙/青绿+品红霓虹/雾气）
- [ ] 时代反差：古典舞者 × 未来霓虹同框成立（核心卖点）
- [ ] 构图符合镜号景别（中近景/全景/中景/特写/特写×3/特写→中近景）
- [ ] 茶元素落点到位（发光泼溅弧线/发光茶汤/旋涡/炸开/快切三连/归位接盏）
- [ ] 姿态符合 §4.2 该镜关键手位（甩盏腾空/捧盏/旋腕/甩茶炸开/拈倾泼/拉盏回眸）

> 6 镜全部过审后，每镜以 `shot<N>_v2_astro.jpg` 为 I2V 首帧（`--input @shotN_v2_astro.jpg`），进入视频生成阶段。

### 4.2 逐镜详解（导演版）

每镜给出：**动作分解**（拍点式，按 0~5s 拆）、**姿态/手位/重心**、**环境/梦境联动**、**镜头与情绪**、**定向 Prompt 提示词**。

#### 镜号 1｜🎣 悬念开场（清纯少女·慵懒侧卧）

> 前 3 秒悬念钩子：**不展示任何宇宙元素**，只给一张清纯无辜的少女脸，让观众好奇"她是谁、她要干嘛"。**环境：现实，暗色极简。**

- **动作分解**：
  - 0-1s：少女慵懒侧卧，一只手托腮，眼神清澈无辜望向前方（面部大特写）
  - 1-2s：镜头缓推，面部占据画面绝大部分，眼眸水光、婴儿肥、额心朱砂清晰
  - 2-3s：唇瓣微抿，发梢一点光尘若隐若现（全片唯一的超自然暗示，埋悬念）
- **姿态/手位**：侧卧托腮（慵懒如小猫）→ 眼神懵懂（好奇）
- **环境**：现实·暗色极简背景，只有极细微星尘光点（悬念，不喧宾夺主）
- **镜头与情绪**：面部大特写缓推，情绪纯净、慵懒、无辜——"这么可爱的少女要干嘛？"
- **Prompt**：`电影级写实照片，真实人物摄影，慵懒纯净质感，面部大特写：真实的人类东方少女，约十六七岁，清纯懵懂稚气未脱，鹅蛋脸带一点婴儿肥，眼眸清澈无辜带着水光，慵懒地侧卧着，一只手托腮，眼神好奇懵懂地望向前方，唇瓣微抿，真实肌肤凝脂质感带毛孔与薄汗，额心一点朱砂；镜头推得很近，她的面部占据画面绝大部分，清澈的眼眸、婴儿肥的脸颊、微抿的唇、额心朱砂都是焦点；画面边缘保留她侧卧姿态的局部：托腮的手、垂落的几缕真实发丝搭在肩头、素纱衣领与肩颈的柔和线条、裙摆边缘微微化开成一点光尘；背景是极简的暗色虚化，只有极其细微的星尘光点若隐若现；她看起来就像一个不谙世事的邻家少女，纯净、慵懒、无辜、惹人怜爱；史诗级电影布光，柔和侧光勾勒面部轮廓，超高细节，8k摄影质感，完全写实不卡通，留白氛围`

#### 镜号 2｜⚡ 极致反差（同一张脸·狂暴灭世）

> 同一张脸突然炸开：**镜 1 越清纯，镜 2 越惊人**。**环境：梦境，星云爆发。**

- **动作分解**：
  - 0-1s：同一张清纯的脸，眼神突然透出毁灭性狂傲神光（表情骤变）
  - 1-3s：张口呐喊，扬手甩出茶盏，星云茶汤泼溅炸开化作超新星爆发
  - 3-5s：发丝衣摆光尘同时炸开，身后深空星云随咆哮撕裂明灭
- **姿态/手位**：表情骤变（清纯→狂傲）→ 甩盏呐喊（腕发力）→ 定格炸裂
- **环境/梦境联动**：甩茶→星云炸成超新星；咆哮→星云撕裂明灭
- **镜头与情绪**：中近景环绕急推，情绪瞬间拉满——炸、反差、停不下来
- **Prompt**：`电影级写实照片，真实人物摄影，神性威严与纯真反差：真实的人类东方少女，约十六七岁，清纯懵懂稚气未脱，鹅蛋脸带一点婴儿肥，眼眸清澈无辜此刻却透出毁灭性的狂傲神光，眼尾上挑，真实肌肤凝脂质感带毛孔与薄汗，额心一点朱砂，她张口呐喊，清纯的脸与狂暴的动作形成极致反差；健康元气不瘦削的少女体态，匀称饱满；真实青丝高束马尾，发梢化开成光尘炸开，发间一支彗尾银簪；她耳畔垂着一枚正常尺寸的星髓珠耳坠——直径约两厘米如一颗大珍珠，半透明珠体内封存着一整条微型银河旋臂，青绿与品红星云在珠内剧烈旋转，珠体辉光迸发，物小意大；颈间星链坠着微缩恒星，右腕星环臂钏，左手正常戒指戒面是微型黑洞；她身着一身改良水墨长裙素纱为底，领口袖口衣摆用极细星尘线绣出星座图谱，腰间纤细银河束带泛青白微光，衣摆边缘化开成星尘又凝回布料；手中握一只温润青瓷茶盏，盏中盛着流动的星云茶汤；她扬手甩出茶盏，星云茶汤泼溅炸开化作超新星爆发，发丝衣摆光尘同时炸开，身后深空星云随着她的咆哮撕裂明灭，青绿品红对冲、明暗层次、颗粒感、体积光，她是一个人也是一个宇宙，外表是清纯元气的邻家少女，狂时如神怒星河为之明灭，史诗级电影布光，超高细节，8k摄影质感，完全写实不卡通，比例协调`

#### 镜号 3｜渐起·承（旋腕摇茶·星系旋臂）

> 梦境渐入佳境。**环境：梦境，手腕即银河轴心。**

- **动作分解**：
  - 0-2s：右手持盏，手腕开始旋绕——以小臂为轴、腕部画圆（摇茶起点）
  - 2-4s：旋绕幅度加大，带动衣料与发丝化作星尘旋动，左臂反向舒展牵引另一侧星流
  - 4-5s：双手交替旋绕，身体随势转体半圈，星系旋臂随之加速
- **姿态/手位**：持盏旋腕（肘固定、腕画圆）→ 双臂对旋（腕带动星系）
- **环境/梦境联动**：手腕=银河轴心——星云被牵引成巨大旋臂，星尘如绸带绕她环绕飞舞
- **镜头与情绪**：中景环绕（镜头绕舞者半圈），情绪从静回升——灵动、流动、渐入佳境
- **Prompt**：`宇宙级意象，时空主宰：充满力量感的现代东方舞者，高马尾长发扬起发丝化作星尘轨迹，皮肤真实质感带汗珠，表情专注投入；宽松飘逸改良水墨渐变长裙，露肩设计；她悬浮于浩瀚星海中央，是宇宙的中心——右手持青瓷茶盏手腕画圆旋绕，盏中发光茶汤旋成小漩涡，整个星系随之旋转，周围星云被牵引成巨大旋臂，星尘如绸带绕她环绕飞舞，左臂反向舒展带动另一侧星流呼应，仿佛她的手腕就是银河的轴心，时间与空间都随主体人物而动，深空星云青绿与品红对冲，史诗级电影打光，超高对比度，真实人物摄影质感`

#### 镜号 4｜⚡ 爆发·转（旋转连击 + 星系炸裂）

> 全片最大爆点：呼应镜 2 的"甩茶"，这次让整个星系随她炸开，情绪最高潮。**环境：梦境，一转身宇宙重启。**

- **动作分解**：
  - 0-2s：舞者俯身蓄力，双臂自下而上如注水（低→高，蓄势）
  - 2-4s：借势旋转连击（两圈以上），裙摆大幅炸开，扬手甩茶
  - 4-5s：星系随之炸裂，亿万星辰四散如超新星爆发，舞者定格半蹲收势
- **姿态/手位**：俯身蓄力（低重心）→ 旋转连击（离心展开）→ 甩茶定格（臂如鞭、腕炸开）

### 5.0 人物造型规格书（v3 定版·先设计后生成）

> 📖 **设计理念（v3）**：不堆砌大面积星云，而是**真实人类 × 微观宇宙**——以"尺度反差"制胜：人只有真实一拳大，耳畔却悬着整个银河。装饰**精而不广**，一尊银河耳坠胜过满身星云。先按《红楼梦》人物出场的精细度把每一处细节描写到位，再让 AI 照此生成。

**人物：星河茶神**（东方少女，约十六七岁）

- **面容**：真实的人类东方**少女**脸——**清纯懵懂、稚气未脱**：鹅蛋脸带一点婴儿肥、眼眸清澈无辜带水光、眉目如画、唇瓣微抿；肌肤真实凝脂质感、细密毛孔与薄汗；额心一点朱砂，那是凝固的超新星核。**表情反差是核心：平时清纯懵懂如不谙世事的少女，爆发时却如神怒灭世**——外表越无辜，动作越惊人。**绝不可卡通化、不可成熟化。**
- **体型**：**健康元气的少女体态**——不瘦削、不病态：身形匀称饱满、面颊带婴儿肥、手臂腿部圆润有活力，像元气满满的邻家少女（讨喜感），而非T台骨感模特。**瘦弱不讨喜，饱满才亲切。**
- **发式**：真实青丝高束马尾，只在发梢末端化开成细碎光尘；发间一支**彗尾银簪**，簪尾坠一粒微缩行星，随转头微微晃荡。
- **耳饰（核心尺度反差）**：左耳一枚**银河耳坠**——细如针尖的银链，下端垂着一整条完整的旋臂银河（肉眼可见的旋臂结构，青绿与品红星云在其中缓缓流转），她一动，星河便在耳侧明灭旋转。**人小、银河大，一尊耳坠即一宇宙。**
- **颈饰**：锁骨间一条**星链**，七颗微缩恒星穿成一线，正中那颗如指甲盖大小，燃着真实的恒星白光。
- **臂/腕**：右腕一只**星环臂钏**——细小的土星环，冰蓝光泽，随旋腕悬浮流转；左手无名指一枚**黑洞戒**，戒面蜷着一粒微型黑洞，吸积盘泛暗金光。
- **衣（精而不广）**：一身改良水墨长裙，素纱为底，**摒弃大面积星云**——只在领口、袖口、衣摆用极细的星尘线绣出星座图谱，针脚如光；腰间一条**银河束带**，细如线却是一整条银河凝成，泛青白微光；行走时衣摆边缘偶尔化开成星尘又凝回布料，如呼吸。
- **器物**：手中一只温润的**青瓷茶盏**（保留凡间质感，与神性形成反差），盏中盛着**流动的星云茶汤**，盏沿悬三粒光点如杯中星。
- **足**：赤足，脚踝系一条极细的星屑链，每走一步散落几点光尘。
- **气质**：她是一个人，也是一个宇宙——狂时如神怒、星河为之明灭；静时如凡人，捧着一盏茶。

**通用视觉锚点（每镜必带，保证一致性）**


> 尺度反差原则：**人真实大小，宇宙微观化做配饰**——银河是耳坠、恒星是项链、土星环是臂钏、黑洞是戒指。宁可一件狠，不要满身光。

> 真实原则：材料可以宇宙化，但面容/皮肤/发丝/布料必须照片级写实，参考 v2 的真实感，禁止卡通化、禁止成熟化。
