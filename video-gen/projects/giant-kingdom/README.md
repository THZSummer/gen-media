> 📌 本目录原名 giant-kingdom（巨人女儿国），v3 改题「蝴蝶女大冒险」。巨人版尝试（v1 奇观 / v2 恐惧逃离）均归档。

## 一、项目背景

- **项目名**：butterfly-girl（蝴蝶女大冒险）
- **类型**：蝴蝶精灵微观冒险短片
- **目标**：主角是**蝴蝶精灵少女**——少女体态 + 蝴蝶翅膀 + **蝴蝶大小**（约 15cm，昆虫量级），能在人类日常场景中飞行冒险。核心卖点是**微观视角的日常冒险**：她在人类的一居室/餐桌/花盆中飞行、躲避、探索，人类日常物品在她眼中是庞然大物（水杯如泳池、书本如城墙、风扇如风暴）。
- **发布渠道**：短视频平台（抖音/视频号/B站竖屏，或小红书横屏）
- **交付时间**：待定（先定向验证基调）

> **主题演进**：v1 巨人奇观（wonder）→ v2 巨人恐惧（fear，巨人比例始终与场景不协调，作废）→ **v3 蝴蝶女大冒险（链式 10 镜，线性强依赖）** → **v4（参考图独立并行，解决线性依赖）**。
> **v3 问题**：每镜必须等上一镜尾帧才能开始，10 镜串行（每镜 2-5 分钟），单点失败全链路断。
> **v4 方案（质量优先，2026-08-09 重设计）**：**分镜关键帧驱动**——每个分镜先生成 3 张关键帧（开始图 / 结束图 / 关键活动图）作为视频参考，模型有完整"起-止-关键动作"轨迹可循，质量大幅提升；每镜独立无依赖（关键帧均从参考图库递归派生，不依赖视频尾帧）。**核心目标是质量，不是并行效率。**

## 四、分镜设计（15s × 5 分镜，一镜到底）

主题母题：**蝴蝶微观冒险**。5 个场景连续，每镜约 3s，一镜到底。

> ⚠️ v3 分镜待重新设计。先出首个分镜定基调（蝴蝶精灵 + 日常场景），确认后补全其余。

### 4.1 速览表（v3 定稿 · 10 镜完整冒险线）

| 分镜 | 场景 | 内容 | 冒险元素 | 音效 |
|------|------|------|----------|------|
| 1 | 书桌+花盆 | 女主慵懒读书，蝴蝶女藏在花盆间隙偷看 | 初次观察 | 翻书声、翅膀轻颤 |
| 2 | 书桌表面 | 蝴蝶女壮胆飞出花盆，落在书页边缘 | 第一次靠近 | 翅膀扇动、纸张 |
| 3 | 茶杯边缘 | 蝴蝶女飞到茶杯边喝水 | 冒险行动 | 水声、翅膀 |
| 4 | 台灯/书本 | 女主翻页的手突然靠近，蝴蝶女惊飞 | 惊吓转折 | 风声、翻页响 |

### 4.2 一次性生成 Prompt（核心）

```bash
# 用官方 API 脚本（复用 step-scenery-v2 的 gen_video.py）
python3 scripts/gen_video.py --duration 15 --ratio 16:9 --resolution 480p \
  "电影级写实，体型反差视觉奇观，一镜到底：一位正常人类大小的清纯少女穿越到巨人女儿国——
  0-3秒她坠落在巨人国青翠草地上，抬头看到远处一位巨大女性的剪影，她的身形高耸入云，发丝如瀑布垂落，脚步落地时大地微微震颤；
  3-6秒一只巨大的手从头顶缓缓降临，五指张开如遮天巨幕，拇指就能遮住整片天空，手背皮肤纹理清晰可见如山峦沟壑，少女在巨手下渺小如尘；
  6-9秒巨人女性缓缓俯身，用掌心轻轻托起少女，少女站在掌心如站在一片大地，巨人瞳孔如清澈湖泊倒映着少女的身影，她好奇地凝视；
  9-12秒巨人低头，如瀑布般的发丝倾泻而下，掠过少女身侧，发丝根根分明如垂落的天幕，少女在发丝间穿行；
  12-15秒少女坐在巨人肩头远眺整个王国，巨人身形巍峨如山脉，她迈步时大地轰鸣震颤，城池在她脚下如玩具；
  全程以巨人为视觉参照系强调体型反差，少女恒定正常大小，电影级打光，完全写实不卡通，音画同步：风声、巨人呼吸声、脚步轰鸣、发丝掠过声"
```

> 说明：
> - 5 个分镜全放进一个 15s prompt，一镜到底
> - 比例语言是关键：`拇指遮天 / 掌心如大地 / 瞳孔如湖泊 / 发丝如天幕 / 一肩一世界`
> - 音效由 generate_audio 原生生成（✅ 官方 API 已验证有效）
> - 生成后若音量偏低：`ffmpeg -i out.mp4 -af "volume=XdB" -c:v copy out_boosted.mp4`

**角色锚点（每镜 prompt 必带开头）**：

```
蝴蝶精灵少女：约3-4厘米，蝴蝶大小，身穿浅蓝色轻盈纱裙，背生一对晶莹的半透明蓝色闪蝶翅膀，
翅膀扇动时洒下细碎光尘，清纯可爱，鹅蛋脸带婴儿肥，眼眸清澈，发丝柔软。
```

```
读书女：约二十出头，穿宽松米色家居服，长发扎成低马尾，安静温柔，坐在书桌旁看书。
```

```
小妹妹：约五六岁，扎着两根小辫子，穿浅粉色家居服，活泼淘气，好奇爱笑。
```

**微观世界设定（v3）**

```
人类日常场景：现代一居室书桌（台灯、茶杯、书本、绿植盆栽），午后阳光，暖色温馨；
在蝴蝶女的视角下：书页如平原、文字如石雕、茶杯如宫殿、手指如巨柱；
蝴蝶女在人类日常物品间飞行冒险，人类物品的庞大体量制造奇幻感。
```

> 核心是**蝴蝶微观视角的日常冒险**——她在人类日常物品间飞行探索，人类物品的庞大体量制造奇幻感。
> ⚠️ 内容安全：日常温馨冒险基调，避免恐怖/不当暗示；女主穿宽松家居服（避免敏感审核），见 [content-safety](../../methods/content-safety/README.md)。

### 5.1 参考图库（v3.5 · 递归生成版）

> v3.5 优化（2026-08-02）：seedream-5.0-pro 支持**以图片为参考生成图片**（多图参考 `@图像N` 融合、参考图生成新视角保形象）。用**递归生成**替代独立生成——从基准图递归派生多角度，形象一致性大幅提升。
> 旧版独立生成图已备份至 `out/refs/v1-independent/`。

**递归生成流程**：

```
基准图（seedream 独立生成）──► 递归派生（以基准图为 --input 参考）
butterfly_base.jpg ──► butterfly_front/back/side（保持形象改视角）
reader_base.jpg    ──► reader_front/back（慵懒吊带短裤）
sister_base.jpg    ──► sister_front
scene_desk_base    ──► scene_desk/door/window（场景图）
```

**角色参考图（多角度 · 三视角齐全）**：

| 角色 | 正面 | 背面 | 侧面 |
|------|------|------|------|
| 蝴蝶女（~3-4cm，浅蓝纱裙+蓝色闪蝶翅膀） | `butterfly_front.jpg` | `butterfly_back.jpg` | `butterfly_side.jpg` |
| 读书女（慵懒吊带+短裤，光脚） | `reader_front.jpg` | `reader_back.jpg` | `reader_side.jpg` |
| 小妹妹（双辫子+粉色家居服） | `sister_front.jpg` | `sister_back.jpg` | `sister_side.jpg` |

**场景参考图（同一房间多机位 · 空间一致）**：

| 场景 | 文件 | 用途 |
|------|------|------|
| 房间全景（空间基准） | `room_base.jpg` | 房间布局基准，派生各机位 |
| 书桌机位（近景+空间延伸） | `scene_desk.jpg` | 主场景 |
| 门口机位（门口→屋内） | `scene_door.jpg` | 门视角/追捕戏 |
| 窗边机位（窗内→窗外） | `scene_window.jpg` | 逃离戏 |

> 三机位图均由 `room_base.jpg` 递归派生（"同一房间同一空间，机位不同"），空间布局一致。

> 使用方式（视频生成时多图 reference）：
> ```
> --input reference_image:@butterfly_front.jpg
> --input reference_image:@reader_noface.jpg
> --input reference_image:@scene_desk.jpg
> prompt: "参考@图像1的蝴蝶女形象、@图像2的读书女背影、@图像3的书桌场景，生成……"
> ```
> ⚠️ **真人参考拦截**：写实人像参考图（读书女正面）触发 `InputImageSensitiveContentDetected.PrivacyInformation`（真人隐私拦截）。解决：**人物参考用"不露脸版"**（背影/低头/远景，`reader_noface.jpg`），既能锁形象又过审；蝴蝶女（精灵）和场景图不受影响。
> 递归生成命令示例（以蝴蝶女正面为基准派生背面）：
> ```
> arkcli +gen --model doubao-seedream-5-0-pro-260628 --profile platform_cn-beijing_accountwide \
>   --size 2560x1440 --output-format jpeg --input @butterfly_front.jpg \
>   "保持@图像1中蝴蝶女的形象、服装和翅膀设计完全不变，改为背面视角……" --save-to out/refs/
> ```

### v4 分镜关键帧方案（质量优先）

**每镜 3 张关键帧**（`out/keyframes/`，seedream 递归生成，角色一致）：

| 帧 | 内容 | 用途 |
|----|------|------|
| **开始图** `shotN_start.jpg` | 镜头起始画面（角色位置/场景/光线） | 视频起始参考 |
| **结束图** `shotN_end.jpg` | 镜头结束画面（该镜情节终点） | 视频结束参考 |
| **关键活动图** `shotN_action.jpg` | 该镜最核心动作/场景瞬间 | 关键动作参考 |

**生成方式**：以参考图库（蝴蝶女多角度/读书女背影/小妹妹/场景图）为 --input 递归派生，prompt 描述该镜情节的关键瞬间。

**视频生成**：每镜独立，`reference_image` 传该镜 3 张关键帧 + 角色图 + 场景图，prompt 引用 `@图像1/2/3...`。无尾帧依赖，单镜可独立重跑。

> 先设计好方案 + 生成关键帧素材 → 用户审视 → 确认后再批量生成视频。
