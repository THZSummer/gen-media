## Core experiment this round: the medium-density base

R19 found that "wide composition ↔ clothing detail density cannot be had together" (the slim base obtained the full figure, but the skirt had almost no embroidery).
R21 built a **medium-density** base to try a middle solution: keep the **form + key ornaments**
(the high-waist form, a gold-thread embroidered chest band set with jade, a gold-set jade waist seal, a gauze pibo), but **does not list everything**
(no cloud collar, earrings, bead counts, or exhaustive enumerations like "stitched one by one").

| Base | Character count | Use |

| **`BASE_E21_MED` (this round)** | **1562** | silhouette + key ornaments |

## Key conclusions

1. **R19's "either-or" has a middle solution**:
   > The clothing description **does not have to choose between "the full list" and "delete everything"**. Keeping **the form sentence + 3–5 key ornaments**
   > holds both the wide composition and the clothing layering. The trigger is **the length of the exhaustive list**, not "mentioning clothing" itself.
2. The three compositions are complete and the quality is stable; the Eastern stage is closed.
