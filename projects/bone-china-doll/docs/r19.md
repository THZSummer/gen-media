用**精确字符串替换**（不是重写 base），只把 `BASE_E18` 的服饰形制句换掉，其余全部继承：

| | 形制句 |

| R18（保留） | `She wears a classical Eastern gown of ivory silk with a crossed collar, wide flowing sleeves and a broad sash ...` |

## 关键结论

1. **形制可以像换零件一样替换**：只动一句服饰句，就得到一整套不同的东方剪影，而
   面容 / 发式 / 首饰 / 材质 / 光线**全部稳定继承**。说明 `BASE_E` 的**分层结构是有效的**，
   后续要扩"汉 / 宋 / 明"任何形制都只需替换同一句。
2. **`花钿` 三次尝试全部失败**（R17 通用语境、R18 通用语境、R19 唐风语境）：
   > **位于面部的细微妆饰（额饰、妆靥类）不可靠**；而**具名器物**（璎珞、步摇、云肩、
   > 金镶玉带、团扇、屏风）几乎一次到位。
   > 结论：**要什么就给它一个"物体"，不要给它一个"妆面细节"。** 本轮起不再尝试 `花钿`。
3. **slim base 的代价**：全身像为了拿到完整构图而删掉服饰清单，副作用是服饰**变素**
   （R19 全身像的裙面几乎无绣）。这是一次清晰的**权衡**：
   > 宽构图 ↔ 服饰细节密度，二者在单张内不可兼得；要两者都有，就用**多张分工**
   > （全身像给轮廓 + 肖像/微距给工艺）。
