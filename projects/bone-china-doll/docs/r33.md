> 返回[项目首页](../README.md) ｜ 上一轮 [R32](r32.md) ｜ 下一轮 [R34](r34.md)
> 用户对 R32 的反馈：**"没有公主的气质，有点老气"**。

## 诊断：R28 那一刀砍掉了两样东西

R30 只查出其中一样（釉面缺陷清单）。这轮把底板逐词审计一遍，第二样是**整块面部描述**：

| 面部/气质关键词 | `BASE_Q10`（phase-2 权威） | R32 底板 |
|------------------|---------------------------|----------|
| `elegant` / `adult` / `young` | ✅ | **0 次** |
| `eyebrow` / `eyelash` / `eye` / `lip` / `nose` / `cheek` | ✅ 全有 | **各 0 次** |
| `blush` | `the faintest soft blush` | **0 次** |

`BASE_Q10` 原本有一整句：

> An **elegant** princess face with refined **adult** proportions: **oval face, high cheekbones,
> straight nose bridge**, serene closed lips, **almond eyes** of realistic size with a subtle crease,
> individually **painted eyelashes**, **eyebrows** painted hair by hair, **the faintest soft blush**.

底板里一个五官词都没有 → 模型只能拿 `princess` 这个泛词自己编脸，
于是编出一张**成熟、五官平淡、面无血色**的通用成年女性脸。

**加重因素**：负向里禁着 `blush makeup / rouge / blush patches / 腮红`（R27 为治"刻意腮红"加的），
而正向又没有任何血色描述 → 面无血色，正是"老气"的直接来源。

## 本轮改动（一组变量：补回"面部 + 气度"）

1. **恢复上面整句面部定义**，并加明确的年龄锚：`a young woman, refined and fresh-faced, never matronly and never severe`
2. **中文层加气度句**：`虽在闲居，气度仍在：肩背挺秀，下颌微收，目光清亮，一份矜贵自持`；
   `神态慵懒闲适，不拘礼数` → 句尾加 `，却自带一份矜贵`
3. **负向去掉"一刀切禁腮红"**（`blush makeup / rouge / blush patches / 腮红`），
   只保留 `circular / doll-like / heavy blush` 与 `applied cosmetics / 浓妆 / 影楼` 类禁令
   → 正向要"极淡血色"，负向不能同时禁掉它

底板 1282 → 1664 字符。三张的 seed / 画布 / 材质句与 R32 **逐字相同**（`assert` 锁死）。

### 两处刻意处理的矛盾

- **年龄要两侧都锚**：项目历史上为治"脸型偏幼儿"（R2–R4）把脸推向成年，
  这次反馈又指向"太老"。所以年龄锚写成"二十出头 + never matronly"，
  而不是笼统的"成年"。
- **慵懒 ≠ 没有气度**：phase-5 的 brief 是"慵懒生活气息"，本轮要的是"公主气度"。
  两者不冲突——加的是"闲居仍有气度"（肩背/下颌/目光），**不动慵懒的设定**，
  也继续禁掉僵硬摆拍（`stiff formal pose / studio pose / 端坐 / 摆拍`）。

## 关键结论

1. **"没有气质"是缺少描述，不是模型能力不足**：补回 phase-2 那句五官定义后，
   睫毛、眉毛、眼型、唇形**逐项生效**——与 `painted eyelashes / eyebrows painted hair by hair`
   这类**具名部件**的可靠性一致（呼应 R19：具名器物可靠）。
2. **颜值关键词的"命中"可以逐项验证**：同 seed A/B 下，R33 相对 R32 的改善可以一一对应到从句
   （睫毛 ← painted eyelashes；眉 ← painted hair by hair；唇颊血色 ← 去掉腮红禁令 + faintest soft blush）。
3. **`adult` 是个危险词**：它是 R4/R5 为治"脸型偏幼儿"引入的，一直留在面部句里。
   在紧肖像下它被字面执行成**皱纹与法令纹**——**为治一个毛病引入的词，会在别的场景下变成新毛病**。
4. **年龄锚的位置太弱**：R33 的 `a young woman ... never matronly` 写在面部句**末尾**、
   位于整条 prompt 中部。按项目自己的"位置即权重"（R23/R24、R27、R28 四次验证），
   这个位置几乎没有权重。→ 直接催生 [R34](r34.md)：把年龄锚**前置**到主语句，
   并把 `adult` 换成 `youthful`、负向补上抗老化词。
