**仍可改进**：
1. **面部过于抛光**：微观釉面/微小气泡/未施釉圈足等要求未被模型执行（Qwen 的"瓷"先验就是完美抛光面）
2. 珠宝金工还停留在"看起来像"，缺**金属铣边、宝石内部折射与包裹体、珍珠珠光层次**
3. 织物质感可再进一步：`raised weft / visible individual stitches / handmade irregularity`
4. 分辨率还有上探空间（1152×1536 → 1280×1712）

## 下一轮改法（R10）

1. 尺寸 → **1280×1712**，steps → **32**
2. 珠宝写实：`engraved silver filigree with crisp milled edges / faceted stones with internal refraction and inclusions / pearls with orient and nacre rings / visible prongs`
3. 织物写实：`silk brocade with raised weft / linen-backed lace / visible individual stitches`
4. 机位转向**珠宝微距 / 刺绣+手部微距 / 窗光肖像**，验证细节在极端裁切下的表现
