# 第 35 轮（R35）· 不是缺陷清单，是 `adult` 这个词

> **本轮先推翻了 R34 的归因**——用的是库里一直躺着的 R25。

## 起因：审计 R25，推翻 R34 的结论

R34 曾判断"瓷面缺陷 ↔ 老气"是同一杠杆两端。审计 phase-4 的材质高地 R25 后发现**该判断错误**：

| | **R25**（成品读作**年轻 + 硬质釉面**） | R30–R34 |
|---|---|---|
| 缺陷清单（5 项） | **逐字相同，全在** | 相同 |
| 面部描述 | **无**（`eyebrow` / `eyelash` / `almond` 各 0 次） | R33 起有 |
| 年龄词 | **无**（`adult` / `young` 各 0 次） | R33 有 `adult` → R34 改 `youthful` |

R25 的成品（`out/r25/bc-r25-skin-square`）是一张**二十出头、额头硬质釉光、颊上一颗缩釉点、
腮上自然薄红**的脸 —— **缺陷清单与"年轻釉面"完全兼容**。

于是真实因果被改写为：

1. **老气的元凶是 `refined adult proportions` 里的 `adult`** —— 它是 R33 从 `BASE_Q10` 恢复的词，
   而它本是 R4/R5 为治"脸型偏幼儿"引入的，**从未被复审**。R34 已修。
2. **R34 瓷感退回，最可能是抗老化负向**（`aged skin / mature face / wrinkles / fine lines`）
   把釉面的表面变化一并压掉了，**而不是缺陷清单在作祟**。

> **教训（已记为沉淀 48）**：归因要拿**已验证的成功样本**做对照。
> R25 一直在库里，先查它就能省掉一整轮错误归因。

## 本轮改动（单变量：撤掉抗老化负向）

`BASE_H13_POSE` **一字未动**；三张的 name / seed / 画布与 R34 完全相同；
只把两张肖像的 negative 从 `NEG_H13_PORTRAIT` 换回 `NEG_H12_PORTRAIT`——
即**删掉 R34 加的那 124 字符抗老化词**（`wrinkles / fine lines / crow's feet / nasolabial folds /
aged skin / mature face / tired eyes / dark circles / 皱纹 / 法令纹 / 眼袋 / 老气 / 疲态`）。
正向的年轻锚（`young` / `youthful` / `in her early twenties` / `dewy clear skin`）**保留**。

### 附带产出：确定性验证（免费）

shot 1 的 prompt / seed / 画布 / negative 与 R34 的 shot 1 **完全相同**，于是它成为一次复现性实验：

| | R34 shot1 | R35 shot1 |
|---|---|---|
| PNG 文件 sha256 | `1c2aaa2187d2fef6…` | `5e47b6b227ae2f30…`（**不同**） |
| 解码后 rgb24 像素 sha256 | `48c5ebabab28591e…` | `48c5ebabab28591e…`（**相同**） |

→ **Qwen-Image 在本服务器上是确定性的**：给定 (prompt, negative, seed, size, steps, cfg, 图)，
输出像素逐字节可复现；PNG 文件哈希不同**仅因为内嵌了执行图/元数据**。
这条实证了项目早先记下的纪律——**比复现性要比像素，不要比文件 sha**。

## 关键结论

1. **抗老化负向确实在压制釉面**：撤掉它（其余全同）后，皮肤从 R34 的"匀净水润真人皮"
   回到带釉面表面变化的瓷调，而**年龄没有反弹**——因为年龄是由**正向锚**（`young` / `youthful` /
   `early twenties`）控制的，不是靠负向压出来的。**正向定义目标，负向不该重复定义目标。**
2. **`adult` 才是老气真凶**，不是缺陷清单。这也解释了为什么 R30–R32 越修越瓷却越老：
   那三轮用的还是 `BASE_H8_POSE` 传下来的措辞，而 R33 引入 `adult` 后才显形。
3. **三阶段落点（供决策）**：

   | 轮 | 皮肤 | 年龄感 | 瓷感 |
   |----|------|--------|------|
   | R25 | 硬质釉光 + 缩釉点 | 年轻 | **最强（近全瓷、偏湿瓷）** |
   | R34 | 水润匀净 | 年轻 | 弱（真人好皮） |
   | **R35** | **釉面纹理 + 秀致五官** | **年轻** | **中（半真半骨瓷）** |

   → R35 是目前**"年轻 + 公主气质 + 瓷面"三者同时在位**的落点。
4. **本轮没有解决、但已知的下一步杠杆**：R25 那句
   `a soft blush of warm colour across the cheeks`（在瓷器语境读作"瓷上彩绘"，R25 的颊上薄红即来自它）
   目前只以 `the faintest soft blush` 的弱化形式存在。若要更接近 R25 的观感，这是下一个可加档的从句。
