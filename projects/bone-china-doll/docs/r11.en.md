## This round's core technique: **framing-first**

The lesson from R10 was that "a long costume description pulls the lens back to a half-body portrait". R11 changed to:

1. **The crop requirement is written first in the prompt**, closed with a negative form:
   `Extreme macro photograph: ONLY the silver filigree tiara and the top of the brown hair fill the entire frame, cropped tight on the crown, nothing else visible.`
2. **For macro cameras, delete the costume list** (keeping only material/light/lens language), to stop the costume words from grabbing weight
3. Three deliberately distinct images: tiara macro (no face) / hands macro (no face) / dark-blue velvet gown half-body portrait

**New lesson**:
> When a macro prompt removes the facial feature description in order to suppress "pulling back", the model **does not draw eyes** (blank porcelain surface). A macro camera still needs a minimal facial feature description (e.g. `painted eyes`), or should use "partial cropping" instead of the extreme negative form "ONLY...".
