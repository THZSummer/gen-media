## 一、为什么要跑这一轮

鹿蜀 R3 已证伪**否定式**抑印（`no seal / no stamp / no writing`，9 张全无效），而本骨法下印面命中率
极高 —— 连本件**已交付的 R7 定稿四角都有淡红印**。于是换假设：**印是"装裱过的旧画"这个先验带出来的**，
不去否定它，而是**改写先验本身**。

四个骨法句与 [鹿蜀 R5](../../lu-shu/rounds/r05-review.md) **逐字相同**（同一实验在两件上各跑一遍）：

| 变体 | 动的那一句 | 假设 |
|------|-----------|------|
| **s1** | 不动（逐字复用现骨法句） | **同轮底座对照** |
| **s2** | `album leaf` → `a single unmounted sheet of xuan paper` | 印属于"册页"这种装裱形态 |
| **s3** | 画面占满整张纸、不留空边 | 印章要有空白才盖得下 |
| **s4** | `aged paper` → `plain white paper` | 印属于"旧画"这个时间先验 |

形态句（`The nine-tailed fox ... nine long tails spread out behind it...`，R7 定稿句）四式逐字不变。

12 张 = 4 式 × 3 seed（1811 / 1922 / 2033），Z-Image-Turbo，1024×1360 / 20 步，**本地免费**，约 60 s/张。
逐字 prompt 见 [`rounds.py` R9](../rounds.py)；产物与 `requests.jsonl` 落在
`work/shanhai-jing/jiu-wei-hu/r09/`（**不入库**）。

**九尾数**：12 张都读作九尾（尾扇展开、尾羽有分缝），与 R7/R8 的点名式结论一致（点名式 8/8、4/4）。

## 四、评分与取舍：为什么**不**换代

R9 的尾巴比 R7 浓得多、九尾读得更清楚，但同一张表上量（A–F，权重见 [PLAN.md](../../../PLAN.md) §五）：

| 维度（权重） | 现定稿 R7 m202 | R9 最优候选 s2-1811 |
|---|---|---|
| A 考据准确（.25） | 4.5（尾淡，读九尾要费力些） | **5**（尾扇清楚、分缝明确） |
| F 气韵生动（.25） | **5**（清雅、留白有呼吸） | 4.5（尾毛偏棉、墨色更重） |
| B 骨法纯正（.15） | **5** | 4.5 |
| C 制式完整（.15） | 4.5 | 4.5 |
| D 辨识度（.10） | 5 | 5 |
| E 系列一致（.10） | **5**（与鹿蜀定稿同一只手） | 4（尾与纸色更重，跟鹿蜀那张不在一个调上） |
| **加权总分** | **4.80** | **4.63** |

> **换代是降级**（而且鹿蜀那边这轮也没换代：它的浓虎纹候选 4.38 < 4.60）。
> 两件一起看，结论是同一个：**"更浓"要付系列一致的账**；要么一起调骨法，要么都不用。

**定稿不变**：画心仍是 R7 m202。但它的**淡印被擦掉了**（见下）。

## 五、修印面缺陷：R7 定稿的两枚淡印

R7 定稿四角 BL、BR 各有一枚**极淡**的模型朱印（4× 放大可见；`seal_check.py` 的环带阈值没检出，
属漏判）。按 PLAN §五 的既有规则用 `scripts/patch_region.py` 擦除：

| 项 | 值 |
|---|---|
| 补丁框 | BL `(0,1266,66,94)`、BR `(950,1284,74,76)`，羽化 12 |
| 自检 | 残留朱砂 22→0、60→0；接缝亮度差 2.0（阈值 ≤30） |
| **逐像素核对** | 与 `controls/jiu-wei-hu-r7-m202-seal-tainted.png` 比：差异 **7024 px，全部落在这两个框内（框外 0 px）** |
| 目视复核 | 四角 12% / 6×：BL、BR 已干净；下缘环带 4× 复核无残留 |
| 制版 | 重跑 `typeset_zanzhi.py`（5 项排版自检通过）；新卡与旧卡的差异只落在补丁对应的一小块（55×57 px） |

> 原样（未擦除）的定稿保留为 `controls/jiu-wei-hu-r7-m202-seal-tainted.png`，便于复现这次擦除。

## 六、沉淀

1. 印是本骨法的**强先验**：位置稳定（右侧两角 + 下缘空白）、措辞压不住（否定式 + 改写先验共 33 张全败）。
2. **机械筛只能"报疑"，不能"报安"** —— 五张被判 CLEAN 的图（鹿蜀 3 + 九尾狐 2）目视全都有印。
3. "更浓的尾巴"与"更浓的虎纹"同源：都是把墨与对比拉高，代价是系列一致（E）。
   下一件若要浓，应当把骨法句的纸色/墨色一起调暗，并**让两件同轮重跑**。
4. 真正能保证干净的仍是：**四角 12% / 6× 目视**（`scripts/corner_sheet.py` 固定版面 + 自检）
   ＋ `scripts/patch_region.py` 擦除（自检 + 逐像素核对）。
