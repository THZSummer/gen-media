## 一、概念：跨越的不是物种，**是界**

**植物长出动物的器官**——「生物拼接」里最有冲击力的方向。
lichen / cordyceps 是"两个生物本来就在一起"，本子主题是**把动物的部件装到植物上**：
**植物界 ↔ 动物界**。

- **底座 ＝ 捕蝇草**（形态很定型：两片夹子 + 边缘硬齿 + 红色内面）
- 供体 ＝ 动物的部位：兽牙 T1（夹子边缘）/ 眼 T2（叶面）/ 舌 T4（夹子内腔）
- ~~爪 T3~~ 已删：捕蝇草没有四肢（规律 74/97）

## 三、规律 99：判据落在「落点」，不是「整体」

开工前我按"三问"预判**它是乙组最难**：捕蝇草形态很定型（规律 92 不利）。
实测**三件全成**。差别在于——

| 部件 | 落点 | 落点性质 | 结果 |
|------|------|----------|------|
| T1 兽牙 | 夹子边缘 | 边界性附属物（**属性**） | ✅ 腾出后完整成立 |
| T2 眼 | 叶面 | 空面（植物上本来没有眼） | ✅ 成立 |
| T4 舌 | 夹子内腔 | 空面（内腔是空的） | ✅ 完整成立 |
| —（对照）鹿颈 / 鱼鳍 | 颈 / 鳍 | **典范结构** | ❌ 改形不改质 / 0% |

> **规律 99：移植难度取决于「落点是不是被典范结构占着」。**
> 92 是整体视角（底座有多定型），99 把它落到局部：
> **整体定型不妨碍移植，只要落点本身是空的、或只是附属属性。**

## 四、补上「腾出占位」的第三类（规律 100）

R1/R2 做了同 seed、同呈现、只换底座写法的对照——占用版 4.55，腾出版 **5.00**：

| 类型 | 例子 | 腾出是否有效 |
|------|------|--------------|
| **结构**（器官、肢体） | 鹿颈/鹿腿、鱼鳍、猫掌、蛇鳞 | ❌ 删了也会被补回来（87/89） |
| **属性**（体表质感、颜色） | 虫体表面的菌丝（cordyceps） | ✅ 有效 |
| **边界附属物**（缘齿、缘毛） | 捕蝇草的边缘齿（本子主题） | ✅ 有效 |

## 五、如实记录的一处不足

期 02 的**眼**只有 4.80：眼球完整、虹膜高光清楚，但**没有眼睑与眼窝**，
放大看有"贴上去"的感觉（C=4）。
→ **规律 101（假设，未验证）**：跨界件的"接缝"决定可信度——
补一处「窝 / 睑 / 接缝」的解剖描述可能显著提高 C 分。留给后续验证。
