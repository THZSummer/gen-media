## 一、概念：跨越的不是物种，是**生命形态**

**树皮 ↔ 兽皮、根系 ↔ 足、年轮 ↔ 骨**——
「生物拼接」里**体量最大**的一组：植物 ↔ 动物，是**两种生命形态**的拼接。

- **底座 ＝ 老树**（换底座时用**枯立木**）
- 供体 ＝ 兽的部位：皮纹 K1 / 足 K2 / 角 K4（~~眼 K5~~ 已删）

## 三、否定结论：**兽足 0% 落地**

根系区**放大 ×1.6 逐张判读**后确认：只有形状漂移，**根还是根**。两条原因：

1. **落点是典范结构**（根系是树的器官，规律 99）
2. **「足」还需要一个关节/肢体作承载面**——树没有腿（规律 74/97）

→ 与 dragon-nines 的「鹰爪必须先用四肢底座」**完全同型**。

## 四、兽皮纹：又一例「属性可腾出」

R1/R2 同 seed、同呈现、只换底座写法：

| 底座写法 | K1 的效果 |
|----------|-----------|
| 占用版：`rough fissured bark` | 树皮「变软变黄」（A=3） |
| **腾出版**：不写树皮 | 树干上出现**明显的兽皮/毛皮带**（A=4） |

→ 与 cordyceps 的虫体表、flytrap 的缘齿同型（规律 96/100）。

## 五、换底座第一次「不降反稳」（规律 102 的补充）

期 04 把底座从**老树**换成**枯立木**，K1 + K4 **同样成立**；
而 flower-bird 玉兰→百合时命中率从 5/5 掉到 1/2。

> **推测**：**属性替换（兽皮纹）与空面新增（兽角）对底座形态的依赖低**；
> 需要几何配合的落点（花心）更敏感（规律 106）。
