## 二、换底座的第一次"不降反稳"（规律 102 的补充）

期 04 把底座从**老树**换成**枯立木**（裂开的枯干 + 裸露根），K1 + K4 两件**同样成立**。
对照 flower-bird：玉兰 → 百合时命中率从 5/5 掉到 1/2。

> **推测**：与**落点性质**有关——**属性替换（兽皮纹）与空面新增（兽角）对底座形态的依赖低**；
> 而 flower-bird 的难题是"从花心里长出一束羽翎"，对花的几何（花心深浅、瓣型）更敏感。

## 三、收官期的诚实标注

期 05 的三件里**只有两件落地**（兽皮 + 兽角），兽足未落地——
成品按 A=4 收，并在期 README 里写明"三件里成两件"。

## 四、沉淀

106. **换底座是否降命中率，取决于落点性质**：属性/空面类落点更稳，
     需要几何配合的落点（花心）更敏感。→ 换底座时优先换"落点性质相同"的底座。
