## 一、概念：典籍里明写的**真实**拼接体

《本草纲目》里的**冬虫夏草**：虫草菌寄生于蝙蝠蛾幼虫，**虫体与子座同现**——
冬天是虫，夏天从虫体上长出菌的子座。
这是典籍里明写的、**真实存在**的拼接体，与 lichen（地衣＝真菌＋藻）同属乙组。

- **底座 ＝ 蛾幼虫**（定型的生物，形态自由度**中低**）
- 供体 ＝ 菌的部位：菌丝覆体 MY1 / 子座 ST1 / 孢子 SP1

## 三、核心发现：**可腾出的是「属性」，腾不出的是「结构」**（规律 96）

R1/R2 做了一组干净对照（同呈现、同 seed、只换底座写法）：

| 底座写法 | 菌丝覆体 MY1 的效果 |
|----------|---------------------|
| **占用版**：`segmented pale body`（虫本身就发白发绒） | 边际贡献小（A=3） |
| **腾出版**：只写头与足（虫体光滑褐色） | 白色菌丝覆体**一眼可辨**（A=4） |

> 对照前几轮的结论：**鹿的腿、鱼的鳍、猫的掌删掉描述也腾不出**（规律 89/87）。
> 差别在于：**器官是结构，体表质感是属性**——
> **属性可以腾出，结构不能。**
>
> 这条与规律 92（底座形态自由度）互补：92 说的是"底座整体有多定型"，
> 96 说的是"**你要腾的那一处到底是结构还是属性**"。

## 四、为什么子座一次就成（本子主题的主力件）

子座同时满足三条有利条件：
1. **空位新增**（虫体上本来没有这根「草」）——规律 67 第 1 档
2. **不同形**（棒状子座 vs 分节虫体）——规律 91
3. **高辨识度**（冬虫夏草这张图本来就在模型的先验里）——规律 90

而且它**不需要额外承载结构**：从体表直接长出，只要有「体表」这个面就有落点
（对比 dragon-nines 的鹰爪"必须有四肢"）。→ **规律 97**。

## 五、收官期换呈现媒介（规律 98）

期 05 是本项目**第一次换呈现媒介**：不再是野外生态照，而是**标本照**
（中性灰背景 + 环形光 + 全焦点，取景句也换成「标本照」）。

部件一字未改，但交付物的身份从「拍到的」变成「收藏的」——
**这是收官期最省力的升级手段**，后面 `tree-beast` 与丙组两册图鉴都可用。

## 六、自评

| 项 | 数 |
|----|----|
| 轮次 | 7 轮（R1 探针 / R2 占用-腾出对照 / R3–R7 五期定稿） |
| 生成张数 | 22 张（zimage，1024² / 1280×1024 / 1024×1280，steps 12） |
| 成品 | **11 张 / 5 期** |
| 平均分 | **4.88**（最低 4.55，最高 5.00） |
| 不合格 | 0 张 |

**一句话**：底座是"定型的虫"却没有想像中难——因为**子座不需要承载结构**、
且**冬虫夏草的先验本身就在模型里**。真正难的只有"同材质替换"的菌丝覆体，
而它靠**腾出体表属性**就补回来了。
