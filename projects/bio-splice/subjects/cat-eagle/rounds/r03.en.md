## 1. The hypothesis to test this round

R2–R5 pinned down that **a named animal renders as a whole** (named in the body slot → a whole animal, its own head included).
So "splitting into parts" should sidestep exactly that—`cat's ears` and `eagle's wings` are **local pieces**,
with no "whole plan" to complete.

So two combinations were picked from the [part list](../parts.en.md):

| Round | Base | Transplant piece | Type |
|----|------|--------|------|
| R6 | **Eagle** (strong species) | cat ears C1 / cat tail C5 / cat paws C4 | strong base + small piece from a weak species |
| R7 | **Cat** (weak species) | eagle wings E2 / eagle tail feathers E5 | weak base + local piece from a strong species |

Sentence pattern (the key change relative to R2–R5):

```
a golden eagle with <移植部位>, <鹰自己的完整描述>      ← R6
a feral tabby cat with <移植部位>, <猫自己的完整描述>   ← R7
```

The base is still **named as a whole** (so that it holds as a whole), while the donor **contributes only a part** (no "a whole X" phrasing appears).

## 3. Two new rules

### 1. Whether a transplant lands depends on whether the base has a "placeholder"

- **A part not mentioned in the base description → the transplant succeeds**: the eagle's description has **no** ears or tail, so cat ears and a cat tail both grew out
- **A part the base already describes explicitly → the transplant is overwritten**: the eagle's description ends with
  `scaled yellow legs with black talons`, and the transplant sentence is written **before** it → the cat paws are overwritten by talons

> So it is not that "a small piece is bound to work"; it is **whether it fights the base's existing description**.
> To fix the cat paws one must first delete the base's talons clause—that requires a **negative prompt**, which this engine lacks.
> This is consistent with the R2–R5 conclusion (no negatives → "subtract something" is unsolvable).

### 2. What is dangerous is "naming an animal as a whole", not "mentioning the species"

Before R7 there was a worry that a strong species (the eagle) would appear as a whole the moment it was mentioned. In practice **all three held**. The difference is the grammatical position:

```
broad folded feathered eagle wings        ← "eagle" 只是**部位修饰语**，没有整体可补完 ✅
a fan of dark brown eagle tail feathers   ← 同上 ✅
whose body is entirely a golden eagle's   ← **整体名词**，模型补完整只鹰 ❌（R2–R5）
```

> **Rule correction** (a narrowing of [r02.md](r02.en.md) conclusion 2):
> what is dangerous is **naming the animal as a whole noun**, not mentioning the species.
> So transplant pieces in the part list are always written as `<part> of X`, never as `X's body`.

## 5. Consolidation

56. **The success of a part transplant depends on the "base placeholder"**: a part absent from the base description can be transplanted in;
    a part the base describes explicitly is overwritten by the base's own description (regardless of ordering—
    the base description overwrites even when it comes later).
57. **Rule narrowed: what is dangerous is "naming a whole noun", not "mentioning a species"**.
    `eagle wings` (a part modifier) is safe, `an eagle's body` (a whole noun) is dangerous.
    This explains why period 01 worked while the eagle-headed cat did not—the former "takes one head in the head slot", the latter "takes a whole animal in the body slot".
58. **Multi-part transplants can be stacked** (ears+tail and wings+tail feathers both hold): as long as no part conflicts with a base placeholder,
    stacking does not interfere. The real ceiling is **the absence of a negative prompt**, not the number of parts.
