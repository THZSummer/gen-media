## 一、项目背景

- **目标**：生成 **细节丰富、真实感强、东方古典公主气质** 的骨瓷国公主（fine bone china doll）图像
- **主题**：**东方古典美女**（R17 起）——东方古典面容、黑发高髻、交领广袖织金、云肩、玉与金 filigree 珠宝
- **生成方式**：ComfyUI（`192.168.3.5:18000`）× Qwen-Image 2512（R7 起；R1–R6 为 Z-Image-Turbo）
- **驱动脚本**：[`run_round.py`](run_round.py)（`python3 run_round.py <轮次>`，prompt 版本化在脚本里）

### 验收标准（每轮逐项打分）

| 维度 | 合格线 |
|------|--------|
| **细节丰富** | 织金与刺绣丝理、珍珠串珠、金 filigree 与玉雕细节、手绘笔触可辨，不糊成一片 |
| **真实** | 骨瓷材质特征成立：半透光、釉面高光；**眼球有虹膜+瞳孔+眼神光**；皮肤是烧制光泽而非塑料哑光 |
| **东方古典 / 公主** | **东方古典面容**（柳叶眉、杏仁眼微挑、鼻梁秀挺、樱唇）、黑发高髻、发簪步摇、交领广袖织金、云肩、玉带、仪态齐备且不廉价 |
| **无畸变** | 手指数量/比例正常、肩颈不切坏、珍珠链不悬空、无多余肢体与漂浮碎块 |
| **画面** | 构图完整（不切手）、光比有主次、背景不抢主体、无灯具入镜 |

> `run_round.py` 的 `unwrap_prompt()` 即此规则，生成时逐条断言「还原 == 原文」（114 段全通过）。
> 取逐字单行原文：`python3 run_round.py <N> --dry`，或读 `out/rN/round.json`。
> 已核对：**R16 与 R21 全部 6 张**在服务器上执行的 `CLIPTextEncode` 文本与本存档**逐字一致**
> （正向 2523–2699 字符 / 负向 360 字符）。
> skill 侧（`comfyui_gen.py` / `comfyui_qwen.py`）自 v1.2 起**默认留档**：每次生成写 `<prefix>.api.json` + `requests.jsonl`，后续轮次无需额外操作。

### 累计有效改进（跨轮沉淀）

1. **眼球**：`painted eyes` → `glass doll eyes with iris/pupil/catchlight`（R2 起生效，最有效的一处）
2. **材质**：补 `fired glaze / specular highlight / craquelure`；避免直接用 `subsurface scattering`（R3 图2 引发色块伪影）
3. **构图**：1:1 → 3:4/4:5 竖构图，避免切肩切手
4. **灯光**：**不要写具体灯具**（"large softbox" 会被画进画面）；改描述光的方向与性质
5. **多样性**：单 batch 5 张会趋同 → 改为**每张独立请求 + 不同机位**

### ⚠️ 反向沉淀：两次退化轮的原因（R11 / R12）

6. **不要为了构图去砍材质词汇**（R11 的错）：Qwen 的服饰/材质词汇是**质量本身**。
   R11 为让"裁切前置"生效而删掉 `BASE_Q9` 微观釉面 + `BASE_Q10` 珠宝金工/织物微距，
   结果裁切拿到手了，但服饰变平、脸部缺质感 —— **构图问题不该用质量词汇去换**。
7. **不要单独下"尖锐高光"的照明指令**（R12 的错，R13 已修正归因）：
   R12 把 `one crisp key light ... every highlight is small and sharp` 单独拎成一条照明指令，
   结果**画面里出现了一盏灯**。但 R13 发现 `BASE_Q10` **本来就含** `one strong key light`
   （在 `sculptural chiaroscuro lighting with one strong key light and deep natural falloff` 里）
   而从未画出灯具 → 真正的诱因是**要求一个可见的锐利强光源**，不是 `key light` 这个词本身。
   光要**融进场景描述**；`softbox / lamp / strobe` 这类具体灯具名词仍然禁用（R4 的老结论）。
8. **不要用"像玻璃 / 高光锐利"来求釉面感**（R12 的错）：会得到**湿塑料**般连绵成片的大高光。
   骨瓷釉面来自**柔和收敛的反射**（R10 窗光即达标），要加质感应加**工艺痕迹**
   （铣边、抛光痕、织物经纬），而不是加强反光。
9. **不要把眼睛当"重点对象"单独强调**（R12 的错）：`open glass doll eyes of realistic size`
   反而让三张脸全部**幼化**；R10 的成年眼型来自 `refined adult proportions ... almond eyes
   of realistic size` 这类**整体比例描述**。
10. **判读纪律**：构图单一（R10）与质量退化（R11/R12）是**两类问题**，不可混为一谈。
    定稿必须按"面部比例 / 釉面 / 服饰工艺 / 画面干净度"四项横向比对，而不是只看本轮新拿到的能力。

### ✅ 正向方法论沉淀（R13–R15）

11. **材质词汇是质量本身，不是可以拿来交换的筹码**（R13 证明）：`BASE_Q10` 只换 seed
    就能复现 R10 水位 → **R11/R12 的退化是删词的确定性后果，不是随机波动**。
    基线一旦确立，后续轮次**只在其上做增量**，不要另起 BASE。
12. **分辨率不是细节杠杆**（R14 证明）：像素 ×2.25，`bytes/px`（细节密度代理）几乎持平，
    4.92 MP 反而最低且耗时 ×5。要提细节必须换机制（更多 steps / 二段精修 / 换模型），
    不是加像素。附带数据：**RTX 4060 Ti 8GB 可跑 4.92 MP 的 Qwen-Image 2512 不 OOM**。
13. **构图靠画布长宽比控制，不靠措辞**（R15 证明）：
    - ✅ **1:2 超竖幅 → 全身像**；**1:1 方形 → 坐姿/中景**
    - ❌ `extreme close-up`（R10）、`ONLY ... fill the frame`（R11）、`seen from behind`（R15）**全部被无视**
    > 机理：长宽比改变潜变量几何形状，模型**只能**用它填满画布 → 构图被强制重排；
    > 措辞只是语义条件，模型可以"选择不服从"。
14. **当某构图在语义层被系统性拒绝时，换到几何层解决**（R15 的通用经验）：
    真微距三轮未果，最终用**裁切**（`make_macro.sh`，从高分辨率成品裁）一次解决，
    而且顺带绕开了 R11「微距无眼」的坑——因为裁切保留了原图完整的眼睛。
    **不要再往 prompt 里加词，换层面。**

### ✅ 第三阶段（东方主题）新增沉淀（R17–R21）

15. **换主题只需替换"文化句"，材质核心逐字继承**（R17 证明）：把 `BASE_Q10` 拆成
    「材质核心句 / 文化句」两类，只换文化句 → 东方古典面容、发髻、交领织金、玉与金 filigree
    **一轮到位**，且二阶段建立的材质真实感**零损失**。反向也成立：**不要重造质量基线**。
16. **服饰描述的长度是构图的敌人**（R18 证明，与主题无关）：
    R10/R13（欧洲）与 R17（东方）三次复现"长服饰清单把镜头拉近"；
    R18 削掉清单立刻拿到全身像。**但 R21 证明不必二选一**：
    > 保留「**形制句 + 3–5 个关键饰件**」，即可同时守住宽构图与服饰层次。
    > 诱因是**穷举式清单的长度**，不是"提到服饰"本身。
17. **描述可靠性分层**（R19/R20 沉淀）：
    | 层级 | 例子 | 结果 |
    |---|---|---|
    | 高 | `璎珞 / 步摇 / 云肩 / 金镶玉带 / 瓷鞋` | ✅ 基本一次到位 |
    | 中 | `团扇 / 屏风 / 木几` | ⚠️ 时成时败（R17/R18 成，R20 败） |
    | 低 | `花钿`（面部妆饰） | ❌ 3 次全败 |
    | 无效 | 视角/裁切措辞（`behind` / `macro` / `ONLY`） | ❌ 一律被忽略 |
    > **要什么就给它一个"可独立成形的物体"，不要给它"妆容细节"或"取景限制"。**
18. **形制可以像换零件一样替换**（R19 证明）：只动**一句**形制句（交领广袖 ↔ 唐风高腰襦裙），
    就得到一整套不同剪影，面容/首饰/材质/光线全部稳定继承 → `BASE_E` 的**分层结构**是
    可扩展的，后续扩汉/宋/明代形制无需改其它句。

### ✅ 第四阶段（半真半骨瓷）新增沉淀（R22–R26）

19. **主语决定"是不是摆件"**（R22 的教训）：前 21 轮越做越像摆件，是因为 prompt 一直写着
    `doll / ball-jointed / museum-vitrine realism / display stand / porcelain slippers`。
    **去除这些词 + 负向禁掉人偶/关节/展台**，她就变回活人。
    ⚠️ 但**不要连"骨瓷材质"一起删**——**主语是活人，材质仍是骨瓷**，两者不矛盾（R23/R24 修正）。
20. **中英分工**（R23 证明）：
    - **中文**写「**有什么**」——人物、神态、首饰、衣裳、环境、道具（中文段一次命中博山炉青烟、
      屏风画意、璎珞、玉环、织金领口，精度高于英文）
    - **英文**写「**是什么做的**」——釉面、半透、显微质感（21 轮验证的材质词汇）
21. **位置即权重**（R24 证明，第 3 次独立验证）：同一段材质文本，从末位搬到**首位**，
    结果从"无釉面"变为"明显釉面"。**最重要的要求写在最前面。**
22. **"细腻" ≠ "光滑"**（R25 证明，本项目关于细节最有价值的一条）：
    笼统写 `microscopic texture` 只会得到**干净光滑**的表面。要给细节，必须**给一份缺陷清单**：
    `pinholes where the glaze pulled back` / `trapped bubbles and blisters` /
    `polishing marks and hairline drag lines` / `orange-peel ripple` /
    `glaze slightly uneven in thickness and colour` / `kiln grit` + `never a uniform flat surface`。
23. **半透光不要点名耳朵**（R24 的坑）：`warm translucency ... of the ears` 会被字面执行，
    长出**精灵尖耳**。改指 `temples / fingertips`，并把 `pointed ears / elf ears / 尖耳 / 精灵耳` 写进负向。
24. **方画布是最便宜的"入微"手段**（R25）：2048² 让脸占的像素翻倍，裁切后才看得见釉面的缩釉点。
    与 R14 不矛盾——加分辨率不涨**全图**密度，但能涨**裁切目标**的可用像素。
25. **"轻盈"要写成物理项，不要用风格词**（R26）：层数 + 厚度（薄如蝉翼）+ 透光（透出里层光影）
    + 边缘（挺括清爽）+ 动态（飘飘欲举、曳地如烟），逐项写出即可得到轻纱；
    只写"飘逸"会得到普通布。**"半纱半骨瓷"的关键是给布料一个"瓷的属性"**
    （`crisp fine weave / cleanly cut edge / the stiffness of porcelain rather than the softness of cloth`）。
26. **妆容需要反向约束**（R22 的坑）：不写"淡妆/素妆"，默认给浓艳口红与现代眉形，出"影楼感"。
    正向写 `妆极淡，近乎素面`，负向禁 `heavy makeup / red lipstick / 浓妆 / 影楼 / 网红妆`。

### ✅ 第五阶段（自然妆容 + 慵懒生活）新增沉淀（R27–R29）

27. **腮红的"刻意感"是位置问题，不是措辞问题**（R27 证明）：R26 那圈明显的圆腮红来自

28. **画布杠杆有方向性**（R27 的限定，R28 确认）：
    - ✅ 超**竖**幅（1:2、1:2.33）能逼出**更高的主体**（站立全身）
    - ❌ 超**横**幅（2:1）**不能**逼出**更宽的主体**——模型会把两侧填成背景，仍出宽画幅胸像
    > 横躺全身**只能靠措辞**拿到，画布只负责不把它裁掉（2.67:1 只是留出空间）。
29. **姿态不是靠"加词"拿到的，是靠"减少竞争描述"拿到的**（R28 证明，"位置即权重"第 4 次验证）：

30. **半透光点名身体部位 = 该部位变成光源**（第 2 次验证，继 R24 之后）：

    > **规则**：写"半透"时**不要指定它是哪个部位**；并把 `glowing hands / 发光的手 / 尖耳`
      等写进负向。
31. **短底板完全可以承载具名饰物**（R29 证明）：R19 的"宽构图 ↔ 服饰细节不可兼得"，

    （交领 / 璎珞 / 玉带）**完全不影响全身构图**。
    > **真正的敌人始终是"穷举式清单的长度"，不是"提到服饰"。**

    > 确认其中没有**已验证的杠杆**。短底板当时被证明有效，掩盖了它同时删掉了什么。
34. **构图的敌人是「服饰穷举清单」，不是「总长度」**（R30 证明，收束 R10/R13/R17/R18/R21/R27/R29）：
    材质句 776 → 1178 字符（整条 1254，**逼近 R27 全身 0/3 时的 1283**），
    三张**仍全部守住全身**。加上 R21/R29 的结论可以定论：
    - ❌ 拉近镜头的是**长服饰清单**
    - ✅ 加**材质密度**不影响构图（只要姿态前置）
35. **"细腻"的判读需要足够像素落在目标上**（R30 的教训）：1600² 的**全身**方画布里，
    脸只占约 180px，放大后细节被插值抹平，**釉面判不了**。
    R25 当年能对"缩釉点"下结论，靠的是 2048² **紧肖像**。
    > **画布大 ≠ 判读板合格**：判读板的取景必须让目标占据足够像素。
36. **具名缺陷清单不会自动被执行**（R30，继 R9 之后第 2 次）：写了
    `pinholes / orange-peel / polishing marks / kiln grit`，画面看不到这些，反而更均匀——
    正是 prompt 明令禁止的 `never a uniform flat surface`。
    > 清单要生效，似乎还需要**让它可见的条件**（见 R31 的 `crisp specular highlights`）。
37. **材质句确实改变皮肤，可用同 seed 消融证明**（R31 证明）：同 seed、同画布、同 negative，
    只差材质句 → 皮肤从"暖调哑光真人皮"变为"冷调均匀带釉光"。**不是 seed 噪声。**
38. **判读板的取景和画布大小是两件事**（R30 的教训，R31 修正）：1600² 的**全身**方画布，
    脸只占约 180px，**釉面判不了**；R25 能对"缩釉点"下结论靠的是 2048² **紧肖像**。
    > 要判微观，**先让目标占据足够像素**——大画布 ≠ 合格判读板。
39. **材质断言是可加档的剂量杠杆**（R32 证明）：同 seed 三级阶梯**单调**递进——
    R29 哑光真人皮 → R31 缎面光泽 → R32 明确釉光。
    关键措辞：`half real skin and half porcelain` 字面上留了一半真人，
    换成 `made of bone china -- the material itself, not a mask` + `Her face is human; her skin is porcelain.`
    才继续往瓷端移动。
40. **同一句从句在不同语境下含义相反**（R27 vs R25 的对照）：`a soft blush of warm colour across the cheeks`
    在 R27 的**活人语境**里读作"涂上去的腮红"（刻意），在 R25 的**瓷器语境**里却读作"瓷上彩绘"（正确）。
    > **不要因为它在某轮是坑就永久拉黑**——先看那轮的主语是什么。
41. **"没有气质"往往是缺少描述，不是模型做不到**（R33 证明）：底板里一个五官词都没有时，
    模型只能用 `princess` 这个泛词编脸，得到的是**成熟平淡的通用脸**。
    补回 phase-2 那句五官定义后，**睫毛、眉毛、眼型、唇形逐项生效**——
    与 R19「具名器物才可靠」同源：**要什么就具名写出什么**。
42. **为治一个毛病引入的词，会在别的场景变成新毛病**（R33 发现）：`adult proportions`
    是 R4/R5 为治"脸型偏幼儿"引入的，一直留在面部句里；在紧肖像下它被字面执行成
    **皱纹与法令纹**，成了"老气"的来源。
    > **纪律**：每当目标转向（从"要成年"转向"要年轻"），回头把**为旧目标写的词**审一遍。
43. **年龄/气质这类属性词必须放在有重量的位置**（R33 的教训 → R34 修正）：
    R33 把 `a young woman ... never matronly` 写在面部句**末尾**（整条 prompt 中部），
    几乎没有权重。按"位置即权重"（已四次验证），年龄锚应当与主语同处最前。
44. **正向要的东西，负向不能同时禁**（R33 的直接教训）：R27 为治"刻意腮红"把
    `blush / rouge / 腮红` 一刀切进负向；到 R33 要"极淡血色"时，正向写了 `the faintest soft blush`、
    负向却还在禁，等于自相矛盾。
    > **规则**：负向只禁**要驱逐的形态**（`heavy / circular / doll-like blush`），
      不要禁**整个概念**。

45. **属性词放末尾等于没写**（R34 证明，"位置即权重"第 5 次）：同一句年龄意思，
    放在面部句**末尾**（R33，整条 prompt 中部）几乎无效；挪到**主语句**（R34，第 41 字符）立即生效。
46. **排除某类特征要写在负向，不要写在正向**（R34）：`wrinkles / 法令纹 / 眼袋 / 老气`
    放进负向后，紧肖像下的细纹显著减少；正向写"不要皱纹"不可靠。
47. ⚠️ **~~"瓷面缺陷"与"老气"是同一杠杆两端~~ → 已推翻**（R35 前的 R25 审计更正）：
    R34 曾推断老气来自缺陷清单。审计 phase-4 高地 R25 后证明**该推断错误**——
    R25 的缺陷清单**与 R30–R34 逐字相同**、且**无任何年龄词**，成品却是
    **二十出头 + 硬质釉光 + 颊上缩釉点 + 腮上薄红**。故：
    - **老气的真凶是 `adult`**（R33 从 phase-2 恢复的词，本是 R4/R5 为治"偏幼儿"引入，从未复审）
    - **R34 瓷感退回更像抗老化负向（`aged skin / mature face / wrinkles`）压掉了釉面**，
      而非缺陷清单
    > **教训**：归因要拿**已验证的成功样本**做对照。R25 一直在库里，先查它就能省掉一整轮的错误归因。
48. **归因要拿「已验证的成功样本」做对照**（R35 的教训）：R34 把"瓷感退回"归因于缺陷清单，
    R35 前审计了库里一直躺着的 R25——**同样的五条缺陷、零年龄词，成品却是年轻+硬质釉面**，
    一句话就推翻了那个归因，省掉一整轮试错。
    > **纪律**：抱怨"某轮变差了"时，**先找历史上做对过的那一轮逐词 diff**，再猜原因。
49. **正向定义目标，负向不要重复定义目标**（R35 证明）：R34 用抗老化负向把细纹压掉了，
    但也把**釉面的表面变化**一起压掉；R35 撤掉那些负向词后釉面回归，而**年龄没有反弹**——
    因为年龄是由正向锚（`young` / `youthful` / `early twenties`）控制的。
    > 负向只该排除**具体要驱逐的形态**，不该承担"定义属性"的职责。
50. **Qwen 在这个服务器上是确定性的**（R35 实证）：同 prompt / negative / seed / 画布 / steps / cfg
    → 解码后像素**逐字节相同**（rgb24 sha 一致）；PNG 文件 sha 不同**仅因内嵌执行图与元数据**。
    > 实证了本项目早先记下的纪律：**比复现性要比像素，不要比文件 sha**。

51. **"更瓷"不等于"更对"**（R32 的反思）：用户 brief 是"**半真实半骨瓷**"，
    而 R25（本项目公认的材质高地）其实**比 brief 更瓷**（接近全瓷）。
    R32 落在中间偏瓷，反而更贴合 brief。**目标不是一个方向上的极值，而是一个区间。**
