## 本轮核心方法修正：**中英分工**

R22 证明了两种语言各自的长处，所以 R23 把它们**分层混写**：

| 层 | 语言 | 负责 | 依据 |
|---|------|------|------|
| **人物 / 神态 / 首饰 / 衣裳 / 环境** | **中文** | "**有什么**" | R22 中文段一次命中博山炉青烟、屏风画意、金璎珞、玉环、织金领口——精度明显高于英文 |
| **材质（肌肤）** | **英文** | "**是什么做的**" | `BASE_Q10` 那套釉面/半透/显微质感词汇有 21 轮验证 |

关键：英文材质段的**主语是 `her skin`**，不是 `a doll`——**活人 + 骨瓷材质，两者并不矛盾**。

同时加了两条反向约束治 R22 的"影楼感"：
- 正向：`妆极淡，近乎素面`、`眉如远山，不施浓黛`、`唇上只点一点浅胭脂`
- 负向：`heavy makeup / bright red lipstick / cosplay / studio glamour shot / 浓妆 / 影楼 / 网红妆`

## 关键结论

1. **中英分工有效**，且解决了 R22 的妆容问题（"素面"约束生效）。
2. **但英文材质段被稀释了**：它排在 ~450 字中文段之后，在 prompt 里几乎没有权重。
   R11（裁切前置）与 R15（画布）早就证明——**prompt 里靠前的东西赢**。
3. **皮肤特写裁切（`out/macro-skin/skin-face-r23.png`）是决定性证据**：
   眼睛极好（虹膜放射纹理、双 catchlight、上下睫毛根根分明），
   但皮肤**没有釉光、没有半透、没有瓷胎微观质感** → 用户的"骨瓷质感"未达标。

## 下一轮改法（R24）

**只改一件事**：把英文材质段**搬到 prompt 最前面**（cfg / steps / 尺寸 / seed 策略全部不动，
保持单变量）。另加两条同向微调：
- 中文段增加**瓷胎层**（釉 / 胎薄处透光 / 釉下气泡，不见肉身毛孔），并**删掉"写实照片"**
  （它在把结果拉向普通摄影皮肤）；
- 负向明确禁掉真人皮肤线索（`human skin texture / pores / matte skin / 真人皮肤 / 哑光皮肤 / 毛孔`）。
