**关键教训（本轮最重要产出）**：
> **Qwen-Image 无视"extreme close-up / macro"这类裁切指令**。当 prompt 里存在**长而具体的服饰描述**时，模型会优先"把整套华服拍全"，从而把镜头拉回标准半身构图。R10 三张全部退化为同一种肖像。

**对策（用于 R11）**：
1. **裁切要求必须放在 prompt 最前面**，并用否定式收口：`ONLY ... fill the entire frame, nothing else visible, no face visible`
2. **微距镜头要弱化服饰描述**，否则服饰词会把镜头拉远
3. 同轮内**刻意拉开差异**（珠宝 / 手部 / 蓝丝绒礼服肖像）

## 下一轮改法（R11，终轮）

1. 构图**前置**：`Extreme macro photograph: ONLY ...` 开头，服饰描述大幅削减或移出
2. 三张拉开：冠冕微距（无脸）/ 手部微距（无脸）/ 深蓝丝绒礼服半身肖像
3. 参数保持 1280×1712 · 32 steps · cfg 3.5
