# 第 7 轮（R7）· 更换引擎：Z-Image-Turbo → Qwen-Image 2512

> 返回[项目首页](../README.md) ｜ 上一轮 [R6](r6.md) ｜ 下一轮 [R8](r8.md)

## 为什么换引擎

R1–R6 用 Z-Image-Turbo（8–16 步）已把**构图、机位、成年比例、构图卫生**解决，但用户判定"细节还是不够丰富、不够真实"。R6 的瓶颈不在 prompt 措辞，而在**引擎的渲染能力上限**：Turbo 蒸馏模型 8–16 步、单一模型，细节层级有限（蕾丝像模制、刺绣无丝理、宝石无镶口）。

服务器模型清单里有更强的选择：

| 候选 | 文件 | 判断 |
|------|------|------|
| **Qwen-Image 2512** | `qwen_image_2512_fp8_e4m3fn.safetensors` + `qwen_2.5_vl_7b_fp8_scaled.safetensors`(type=`qwen_image`) + `qwen_image_vae.safetensors` | ✅ 采用：20B 级 MMDiT，细节/写实显著更强，且**支持真正的 negative prompt** |
| boogu-image-turbo | `boogu_image_turbo_fp8_scaled.safetensors` | 备选，未测 |
| z-image-turbo | 现用 | 保留作快速草稿引擎 |

> 探测发现服务器有 `TextEncodeQwenImage21` 节点（原生 prompt+negative_prompt），但经典 `CLIPTextEncode` + `qwen_image` clip type 已验证可用，故采用经典图。

## 新增能力（已固化进技能）

`skills/text-to-image-comfyui/scripts/comfyui_qwen.py` —— 第二个引擎，与 `comfyui_gen.py` 共用排队/轮询/下载：

```bash
python3 comfyui_qwen.py --check                     # 校验三个模型文件在位
python3 comfyui_qwen.py --prompt "..." --negative "..." \
  --width 1024 --height 1360 --steps 24 --cfg 3.0 --seed 7 --out-dir out/
```

图结构：`UNETLoader → ModelSamplingAuraFlow(shift 3.0) → KSampler(euler/simple, cfg)`；
`CLIPLoader(qwen_image) → CLIPTextEncode 正/负`；`EmptySD3LatentImage → KSampler → VAEDecode → SaveImage`。

项目侧：`run_round.py` 升级为**双引擎**，轮次配置新增 `engine` 字段（`zimage` / `qwen`）。

### 负向提示词（NEG_Q）

```
cracks, crazing, crackle pattern, broken, damaged, chipped, dirty, dust, stains, plastic, vinyl,
waxy skin, cartoon, anime, chibi, toy-like proportions, oversized eyes, blurry, low detail,
low resolution, oversaturated, harsh flash, cgi, 3d render, extra limbs, extra fingers, deformed
hands, floating objects, text, watermark, signature, logo, busy background
```

> R6 之前 `craquelure`（开片）被当成"细节"写进正向，Qwen 把它放大成**满脸裂纹**（见 `.scratch/qwen-probe.png`）。R7 起把裂纹全部移入负向，改为 `pristine flawless glaze`。

## 自检

| 画面 | ★★★★★ | ↑ 背景干净、光比有主次 |

**结论：R7 是全项目最大的一次跃升，引擎切换的价值远超继续调 prompt。** R7 起 3 张/轮。

**仍可改进**：
1. 面部"无瑕到塑料感"倾向（porcelain 本应如此，但需一点釉面微观起伏）
2. 光线偏平光，缺乏雕塑感 —— 下一轮上 **chiaroscuro / Rembrandt**
3. 服饰可以更华丽（brocade、金线、宝石镶爪）
4. 分辨率可再上一档（1024×1360 → 1152×1536）换细节
