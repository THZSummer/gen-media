## 关键结论

1. **裁切法在东方主题下同样有效**，且**不需要任何新 prompt 措辞**——直接复用 R17/R18 的底座即可。
   这再次确认：**微距是几何问题，不是语义问题。**
2. **"场景物体"的可靠性低于"具名首饰"**：
   - 高可靠：`璎珞 / 步摇 / 云肩 / 金镶玉带 / 瓷鞋`（器物类）
   - 中可靠：`团扇 / 屏风 / 木几`（R17、R18 成功，R20 失败 → 不稳定）
   - 低可靠：`花钿`（面部妆饰，三次全败）
   > 规律：**越靠近"可独立成形的实体物件"越可靠；越靠近"妆容/取景"越不可靠。**
