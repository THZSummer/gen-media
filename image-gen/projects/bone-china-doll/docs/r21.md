## 本轮核心实验：中间密度底座

R19 发现"宽构图 ↔ 服饰细节密度不可兼得"（slim base 拿到全身像，但裙面几乎无绣）。
R21 造了一个**中间密度**底座试中间解：保留**形制 + 关键饰件**
（高腰形制、金线绣胸带嵌玉、金镶玉腰封、纱罗披帛），但**不列全清单**
（不写云肩、耳坠、滚边颗数、"stitched one by one"这类穷举）。

| 底座 | 字符数 | 用途 |
|------|--------|------|
| `BASE_E18_SLIM`（R19 全身像用） | 1329 | 只要轮廓 |
| **`BASE_E21_MED`（本轮）** | **1562** | 轮廓 + 关键饰件 |
| `BASE_E18`（肖像/坐姿用） | 3088 | 全清单 |

## 关键结论

1. **R19 的"二选一"有中间解**：
   > 服饰描述**不需要在"全清单"与"全删除"之间二选一**。保留 **形制句 + 3–5 个关键饰件**，
   > 就能同时守住宽构图与服饰层次。诱因是**穷举式清单的长度**，不是"提到服饰"本身。
2. 三张构图齐全、质量稳定，东方阶段收束。

## 东方主题最终配方（可复现）

```
引擎      Qwen-Image 2512 (fp8) + qwen_2.5_vl_7b (type=qwen_image) + qwen_image_vae
BASE      BASE_E18（肖像/坐姿）· BASE_E21_MED（全身像）· BASE_E19（唐风变体）
负向      NEG_Q
采样      32 steps · cfg 3.5 · euler/simple
构图      画布长宽比：3:4 肖像 / 1:2.2~2.3 全身 / 1:1 坐姿
微距      make_macro_east.sh 从 3.43MP 底板裁切
可靠名词  器物类：璎珞 · 步摇 · 云肩 · 金镶玉带 · 瓷鞋 · 团扇 · 屏风
不可靠    花钿（面部妆饰，3 次全败）· 视角/裁切措辞 · 长服饰清单（拉近镜头）
```
