# 第 34 轮（R34）· 把年龄锚放到有重量的位置

> 🌐 语言：**中文** ｜ [English](r34.en.md)

> 返回[项目首页](../README.md) ｜ 上一轮 [R33](r33.md)
> R33 补回面部描述后，睫毛/眉毛/唇色/颊色逐项生效，但 2048² 紧肖像**仍偏成熟**。
> 同 seed A/B 指出老在哪里：眼周细纹、法令纹、额头细纹。

## 本轮改动（一组变量：年龄锚前置 + 负向排除老化）

| # | 改动 | 理由 |
|---|------|------|
| 1 | 主语句 `a living Eastern classical princess` → `a **young** living Eastern classical princess` | 位置即权重——锚放在**第 41 个字符**（R33 把年龄锚放在面部句末尾、整条 prompt 中部，几乎没有权重） |
| 2 | 面部句 `refined **adult** proportions` → `refined **youthful** proportions` | `adult` 是 R4/R5 为治"脸型偏幼儿"引入的词，在紧肖像下被字面执行成皱纹 |
| 3 | 年龄锚加强：`a young woman` → `a young woman **in her early twenties**, … , with **dewy clear skin**` | 给出可执行的年龄与肤质 |
| 4 | **负向补抗老化词**：`wrinkles, fine lines, crow's feet, nasolabial folds, aged skin, mature face, tired eyes, dark circles, 皱纹, 法令纹, 眼袋, 老气, 疲态` | Qwen 吃真负向，排除老化特征应写在负向侧（而不是正向写"不要皱纹"） |

底板 1664 → 1723 字符。三张的 seed / 画布 / 材质句与 R33 **逐字相同**（`assert` 锁死）。

## 关键结论

1. **年龄锚的位置决定它是否生效**（"位置即权重"第 5 次验证）：同一句意思，
   放面部句末尾（R33）几乎无效，放主语处（R34）立即生效。
2. **负向是排除老化特征的正确位置**：`wrinkles / 法令纹 / 眼袋 / 老气` 放进负向后，
   紧肖像下的细纹显著减少。正向写"不要皱纹"是不可靠的。
3. ~~**"瓷面缺陷"与"老气"是同一根杠杆的两端**~~ ← **本条已被 R35 前的 R25 审计推翻，见下方更正**。
   当时的推断是：R30–R32 写进去的 `polishing marks / hairline drag lines / orange-peel ripple`
   在皮肤上被执行成皱纹，所以是"老气"的一个来源。**这个推断是错的。**

   ### ⚠️ 事后更正（R35 之前，审计 R25 得出）

   审计 phase-4 的材质高地 R25（`out/r25/bc-r25-skin-square`）后推翻本条：

   | | R25（读作**年轻 + 硬质釉面**） | R30–R34 |
   |---|---|---|
   | 缺陷清单（5 项） | **逐字相同，全在** | 相同 |
   | 面部描述 | **无**（eyebrow/eyelash/almond 全 0） | R33 起有 |
   | 年龄词 | **无**（`adult` / `young` 各 0 次） | R33 有 `adult`，R34 改 `youthful` |

   R25 的成品是一张**二十出头、额头硬质釉光、颊上一颗缩釉点、腮上薄红**的脸——
   **缺陷清单与"年轻釉面"完全兼容**。

   因此真实因果是：
   - **老气的元凶是 `refined adult proportions` 里的 `adult`**——它是我在 R33 从 `BASE_Q10`
     恢复过来的词，而它本是 R4/R5 为治"脸型偏幼儿"引入的，**从未被复审**。
   - **R34 瓷感退回，最可能是抗老化负向**（`aged skin / mature face / wrinkles / fine lines`）
     把釉面的表面变化一并压掉了，**而不是缺陷清单在作祟**。
   → R35 因此改为**只撤掉抗老化负向**（单变量），保留完整缺陷清单与正向年轻锚。
4. **R30→R34 的完整轨迹**（供决策）：
   | 轮 | 皮肤读作 | 优点 | 缺点 |
   |----|----------|------|------|
   | R29 | 暖调哑光真人皮 | 自然、有活人血色 | 无瓷感 |
   | R31 | 真人皮 + 缎面光泽 | 瓷感初现 | 五官平淡、老气 |
   | R32 | 柔和整体釉光 | 半真半骨瓷的平衡点 | 五官仍平淡、老气 |
   | R33 | 瓷感 + 精致五官 | 睫毛/眉/眼/唇逐项到位、有血色 | 细纹显现 → 老气 |
   | **R34** | **水润年轻皮肤 + 瓷光** | **年轻、秀致、气色好** | **瓷面缺陷被压掉，瓷感略退** |
