# Round 35 (R35) · It is not the defect list, it is the word `adult`

> 🌐 Language: **English** | [中文](r35.md)

> Back to [project index](../README.en.md) ｜ Previous round [R34](r34.en.md)
> **This round first overturns R34's attribution** — using R25, which had been sitting in the repository all along.

## Cause: auditing R25, overturning R34's conclusion

R34 once judged "porcelain-surface defects ↔ old look" to be two ends of the same lever. Auditing phase-4's material highland R25 showed **that judgement to be wrong**:

| | **R25** (the final reads as **young + hard glaze**) | R30–R34 |
|---|---|---|
| Defect list (5 items) | **Word-for-word identical, all present** | Same |
| Facial description | **None** (`eyebrow` / `eyelash` / `almond` 0 occurrences each) | Present from R33 |
| Age words | **None** (`adult` / `young` 0 occurrences each) | R33 has `adult` → R34 changed it to `youthful` |

R25's final (`out/r25/bc-r25-skin-square`) is a face that is **in her early twenties, with hard glaze sheen on the forehead, a glaze pull-back pinhole on the cheek
and a natural faint blush on the cheeks** — **the defect list and a "young glaze surface" are fully compatible**.

So the real causality is rewritten as:

1. **The culprit for the old look is `adult` in `refined adult proportions`** — a word R33 recovered from `BASE_Q10`,
   originally introduced in R4/R5 to cure an "infantile face shape" and **never re-reviewed**. R34 already fixed it.
2. **The porcelain feel receding in R34 is most likely the anti-aging negatives** (`aged skin / mature face / wrinkles / fine lines`)
   suppressing the glaze's surface variation along with them, **rather than the defect list at work**.

> **Lesson (recorded as distillation 48)**: attribution must use a **validated successful sample** as control.
> R25 had been in the repository all along; checking it first would have saved a whole round of wrong attribution.

## Changes this round (single variable: remove the anti-aging negatives)

`BASE_H13_POSE` is **untouched**; all three share exactly R34's name / seed / canvas;
only the two portraits' negative is switched from `NEG_H13_PORTRAIT` back to `NEG_H12_PORTRAIT` —
i.e. **the 124 characters of anti-aging words added in R34 are deleted** (`wrinkles / fine lines / crow's feet / nasolabial folds /
aged skin / mature face / tired eyes / dark circles / 皱纹 / 法令纹 / 眼袋 / 老气 / 疲态`).
The positive young anchors (`young` / `youthful` / `in her early twenties` / `dewy clear skin`) are **kept**.

### Incidental outcome: a determinism check (free)

shot 1's prompt / seed / canvas / negative are **exactly the same** as R34's shot 1, so it becomes a reproducibility experiment:

| | R34 shot1 | R35 shot1 |
|---|---|---|
| PNG file sha256 | `1c2aaa2187d2fef6…` | `5e47b6b227ae2f30…` (**different**) |
| Decoded rgb24 pixel sha256 | `48c5ebabab28591e…` | `48c5ebabab28591e…` (**identical**) |

→ **Qwen-Image is deterministic on this server**: given (prompt, negative, seed, size, steps, cfg, graph),
the output pixels are byte-for-byte reproducible; the PNG file hash differs **only because the execution graph/metadata is embedded**.
This empirically confirms the discipline recorded earlier in the project — **compare pixels for reproducibility, not file shas**.

## Key conclusions

1. **The anti-aging negatives really were suppressing the glaze**: after removing them (everything else identical), the skin goes from R34's "uniform dewy real-human skin"
   back to a porcelain tone with glaze surface variation, and **the age does not bounce back** — because the age is controlled by the **positive anchors** (`young` / `youthful` /
   `early twenties`), not squeezed out by negatives. **The positive defines the goal; the negative should not define it a second time.**
2. **`adult` is the real culprit for the old look**, not the defect list. This also explains why R30–R32 became more porcelain yet older with each fix:
   those three rounds still used the wording handed down from `BASE_H8_POSE`, and the problem only became visible after R33 introduced `adult`.
3. **Three landing points (for decision-making)**:

   | Round | Skin | Age impression | Porcelain feel |
   |----|------|--------|------|
   | R25 | Hard glaze sheen + pull-back pinholes | Young | **Strongest (close to fully porcelain, leaning wet porcelain)** |
   | R34 | Dewy and uniform | Young | Weak (good real-human skin) |
   | **R35** | **Glaze texture + refined features** | **Young** | **Medium (half real, half bone china)** |

   → R35 is so far the landing point where **"young + princess temperament + porcelain surface" all hold at once**.
4. **A next-step lever not solved this round but already identified**: R25's
   `a soft blush of warm colour across the cheeks` (which reads in a porcelain context as "painting on porcelain"; R25's faint cheek blush comes from it)
   currently exists only in the weakened form `the faintest soft blush`. To get closer to R25's look, this is the next clause to notch up.
