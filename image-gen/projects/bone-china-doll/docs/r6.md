## 参数

| 项 | 值 |
|----|----|
| 尺寸 | 1024×1360 |
| steps | **16**（R5 为 12，R1–R4 为 8） |
| seed | 600 / 610 / 620 / 630 / 640 |
| 驱动 | `python3 run_round.py 6` |
| 输出 | `out/r6/bc-r6-<机位>_00001_.png` + `round.json` |

## 本轮追加的细节指令（在 BASE5 基础上）

```
uniform glossy fired glaze ... with visible micro glaze texture and fine craquelure lines
individually rendered eyelashes
a hand-painted rose motif on the skirt
tiny hand-sewn beadwork
photorealistic macro photograph ... ultra-detailed
```

机位：`macro-face`（微距特写）/ `bouquet`（瓷花捧花）/ `fan`（折扇）/ `seated-hands`（坐姿关节手）/ `full-figure`（全身）

## 自检

| 维度 | 评分 | 变化 vs R5 |
|------|------|-----------|
| 细节丰富 | ★★★★★ | ↑↑ **手绘玫瑰纹样、瓷花捧花、水晶珠饰**出现；裙面蕾丝网眼与珠串层次最丰富 |
| 真实 | ★★★★☆ | ↑ 釉面高光 + 微观质感 + 薄处透光；瓷质可信 |
| 公主 | ★★★★☆ | ≈ 成年比例稳定，仪态端庄 |
| 无畸变 | ★★★★ | ≈ 无漂浮物/无多余肢体；`fan` 图持扇手略僵 |
| 画面 | ★★★★☆ | ↑ 五机位齐备，背景干净 |

**遗留问题**（可作后续项目起点）：
1. `macro-face` 未真正收成微距（仍是半身），需更强构图词约束
2. `fan` 图的面部与手部略失真，属该 seed 偶发
3. 全身像面部偏小，五官细节不足（受分辨率与景别限制）
