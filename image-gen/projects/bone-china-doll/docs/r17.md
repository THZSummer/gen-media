## 变更方法：只换文化要素，材质核心逐字继承

R13 已证明"质量来自 `BASE_Q10` 的材质词汇"，所以本轮**不新造质量基线**，
而是把 `BASE_Q10` 逐句拆开，**只替换文化相关句**：

| `BASE_Q10` 句 | 处理 | 结果（`BASE_E`） |
|---|---|---|
| `Pristine flawless ivory porcelain ... dust-free` | **逐字保留** | 同（已校验 `in BASE_E == True`） |
| `Visible ball-joint seams at the neck and wrists` | **逐字保留** | 同 |
| `An elegant princess face ...` | **替换** | 东方古典面容：柔和鹅蛋脸、柳叶眉、秀挺鼻梁、樱唇、杏仁眼微挑、深棕虹膜 |
| `A gown of real white lace ... pearl drop earrings` | **替换** | 交领广袖象牙色丝绸、织金云纹牡丹、密绣珍珠滚边、**金镶玉带**、**云肩**、金镶玉耳坠 |
| `Fine art studio lighting ... neutral backdrop` | 逐字保留 | 同 |
| `Extravagant costume craft: ... enamelled details` | **替换材质名** | 丝绸织金、密绣丝理、珠绣、**玉（软蜡光泽 + 内部纹理）**、金 filigree |
| `Sculptural chiaroscuro ... one strong key light ...` | **逐字保留** | 同（R13 已证明该句安全） |
| `Extremely fine porcelain surface: ... sensor grain` | **逐字保留** | 同 |
| `Jewellery realism: ...` / `Fabric realism: ...` | **替换材质名** | 金 filigree / **玉内部纹理** / 珍珠珠光；丝绸经纬 / 绣缎 / 亚麻内衬 |

> ✅ 残留检查：`lace / tiara / sapphire / blue sash / european / western` 在 `BASE_E` 中**全部为 False**。

**刻意保留**（有实验依据，不许"顺手优化"）：`pristine / flawless / perfectly smooth` 等完美词、
`one strong key light`。**刻意规避**：不单独下锐利照明指令、不单独强调眼睛大小、不写视角/裁切措辞。

## 关键结论

1. **主题切换一轮到位**：只替换文化要素、保留材质核心的做法**有效**——东方古典面容、发髻、
   交领广织金、玉与金 filigree 全部按描述落地，且**没有损失**二阶段好不容易建立的材质真实感。
2. **R10/R13 的老规律在东方主题下同样成立**：`full-figure` 那张的服饰描述更长（交领广袖+织金+
   云肩+玉带），模型再次选择"把华服拍全"而**拒绝拉到全身**。
   → 说明该规律与主题无关，是 Qwen 对**长服饰描述**的固有反应。
3. **道具与场景能被执行**：`round silk fan lying on the table`、`carved wooden folding screen`
   都被准确画出——这与"裁切/视角措辞"不同：**场景物体是"可添加的内容"，会被执行；
   取景要求是"对画布的限制"，会被忽略**。这是本轮新增的一条判读。
