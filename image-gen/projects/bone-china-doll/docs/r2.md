**新问题**：
1. 灯光词把**灯具本身画进画面** → 需去掉具体灯具描述
2. 脸型仍是**幼儿娃娃比例**（大额头、圆脸、大眼）→ 缺"成年公主比例"约束
3. 腮红过重 → 显廉价
4. 5 张同质化（同一 batch 构图趋同）→ 改为**每张不同机位**

## 下一轮改法（R3）

1. 五张分别用**不同机位/姿态**：正面 / 持扇 3/4 / 侧逆光透光 / 坐姿关节手 / 全身
2. 加入 **elegant serene princess, refined oval features, slender neck, not a toddler** 约束脸型
3. 腮红降为 **very subtle soft blush**
4. 背景改 **clean seamless studio backdrop, no studio equipment visible**
5. 用侧逆光尝试呈现**骨瓷透光**
