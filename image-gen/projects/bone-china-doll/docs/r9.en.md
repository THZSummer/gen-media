**Still improvable**:
1. **The face is over-polished**: the micro glaze/micro bubbles/unglazed foot rim requirements were not executed by the model (Qwen's "porcelain" prior is a perfectly polished surface)
2. The jewellery metalwork still only "looks like it"; it lacks **milled metal edges, internal gemstone refraction and inclusions, pearl orient layering**
3. Fabric texture can go further: `raised weft / visible individual stitches / handmade irregularity`
4. Resolution still has headroom (1152×1536 → 1280×1712)

## Changes for the next round (R10)
