## 诊断：为什么越做越像摆件

复盘前 21 轮，prompt 里一直在强化"她是一件物品"：

| 用词 | 效果 |
|------|------|
| `handcrafted ball-jointed bone china doll` | 主语就是**人偶** |
| `photographed like a real physical object on a table` | 明确是**物件** |
| `Visible ball-joint seams at the neck and wrists` | 球形关节缝 = **摆件特征** |
| `museum-vitrine realism` | **陈列柜** |
| `porcelain slippers` / `carved wooden stand` | **展台与配件** |

所以三轮"东方化"之后，画质越来越好，但**越来越像博物馆里的一座人偶**。

## 本阶段三条改动

1. **正向彻底删除**人偶 / 关节 / 展台 / 陈列柜的所有词，主语改为"一位东方古典公主"；
2. **负向明确禁掉"摆件"**（`NEG_H` = `NEG_Q` + 人偶/球形关节/关节缝/展台/陈列柜/底座/雕像，中英双语）；
3. **prompt 改用中文**，按红楼梦人物出场笔法**逐层白描**：
   发式 → 面 → 眉 → 目 → 鼻 → 唇 → 肌肤 → 首饰 → 衣裳 → 神态 → 环境 → 光 → 镜头。
   > 依据：Qwen-Image 的文本编码器是 **Qwen2.5-VL**，中文语义对齐应优于英文转译——
   > 这是前 21 轮**从未试过**的杠杆。

## 关键结论

1. **中文 prompt 对"物件与场景"的可控性极强**：博山炉的香烟、屏风画意、璎珞圈、织金绣样、
   玉环腰饰——一次全部命中，精度明显高于英文版（英文版常丢道具）。
   > **中文适合写"有什么"（人、物、景、态）；英文适合写"什么材质"（釉面、半透、显微质感）。**
2. **去摆件化与保骨瓷质感是两个可以解耦的目标，本轮错把它们绑在了一起**：
   我把"doll / porcelain"词汇一并删掉后，模型就把她当成普通真人来画，皮肤自然变成真人皮肤。
   **正确做法：主语是活人，材质仍然是骨瓷**——两者并不矛盾。
3. **妆容需要反向约束**：不写"淡妆/素妆"，模型默认给浓艳口红与现代眉形，出"影楼感"。

## 下一轮改法（R23）

1. **中英混写**（本轮最重要的方法修正）：
   - **中文段**：人物 / 神态 / 首饰 / 衣裳 / 环境（R22 已证明可控）
   - **英文段**：**材质**——复用 `BASE_Q10` 那套已验证的骨瓷釉面词汇，但**主语是"her skin"**
     而不是"a doll"：`fired glaze` / `delicate warm translucency at the ears, nose wings and
     fingertips` / `microscopic glaze texture with polishing marks` / `microscopic bubbles
     suspended inside the glaze` / `absolutely no CGI smoothness`
2. **加服装/妆容的反向约束**：`不施浓妆`、`唇上只点一点浅胭脂`、`眉如远山`，压掉影楼感
3. **皮肤细节的最终手段仍是裁切**：从 3.43MP 底板裁面部特写，直接检验"细致"是否达标
