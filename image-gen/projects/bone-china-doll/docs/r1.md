## Prompt（原文）

```
Museum-quality bone china princess doll, collector-grade photorealistic portrait photograph.
Porcelain skin with soft translucency, fine hand-painted rosy blush, delicate hand-painted arched
eyebrows, long curled eyelashes, glossy lips. Intricate white lace gown with woven silver threads,
beaded pearl bodice, soft blue satin sash, tiny pearl buttons. Silver tiara with small diamonds,
pearl drop earrings, a single sapphire pendant. Painted porcelain hands with slender jointed fingers.
Centered head-and-shoulders portrait, soft diffused studio light with gentle specular highlight on the
porcelain cheek, dark blue-black velvet backdrop, shallow depth of field, 85mm macro lens,
ultra-detailed surface glaze, subtle craquelure, no text
```

## 自检

| 维度 | 评分 | 依据 |
|------|------|------|
| 细节丰富 | ★★★☆ | 蕾丝/珍珠/冠冕可辨 |
| 真实 | ★★☆ | 低饱和**塑料娃娃感**；无半透光与开片；**眼睛是扁平画眼**，无虹膜、无眼神光 |
| 公主 | ★★★★ | 冠冕+蓝宝石+珍珠+蕾丝礼服齐备 |
| 无畸变 | ★★☆ | 方形构图切手臂/手；图4 珍珠链悬空、双肩被切；图5 手指过长 |
| 画面 | ★★★☆ | 光比偏平；5 张构图几乎相同 |

**根因**：①"painted eyes / painted hands" 等词把模型引向**画出来的玩具眼**；②缺骨瓷材质物理词；③1:1 构图对竖构图主体不友好。

## 下一轮改法（R2）

1. 眼球：改为 **glass doll eyes + iris + pupil + catchlight**（玻璃眼球、虹膜、瞳孔、眼神光）
2. 材质：补 **subsurface scattering / fired glaze / specular highlight / craquelure**
3. 构图：**1024×1365（3:4）** 竖构图
4. 灯光：升级为 **large softbox key + rim light**、中画幅 + 120mm macro
5. 多样性：每轮换 seed 与镜头/姿态变量
