# 第 30 轮（R30）· 找回 phase-5 丢掉的那层材质

> 🌐 语言：**中文** ｜ [English](r30.en.md)

> 返回[项目首页](../README.md) ｜ 上一轮 [R29](r29.md) ｜ 下一轮 [R31](r31.md)
> 起因：回看 `out/final-set-life/` 与 `out/final-set-gauze/` 的并排差异——
> phase-5 那批读起来是"**穿汉服的真人在拍照**"，骨瓷质感没了。

## 诊断（不是审美漂移，是机械原因）

把两个阶段的底板逐字对比，差异不在措辞水平，而在**清单被删了**：

| 底板 | 长度 | 具名釉面缺陷 |
|------|------|--------------|
| `BASE_H4_EN`（phase-4 材质层） | 844 字符 | **八项全在** + `never a uniform flat surface` + `absolutely no CGI smoothness and no plastic` |
| `BASE_H8_POSE`（phase-5 短底板） | 776 字符 | **只剩 `fine micro-texture in the glaze`** 一句泛称 |

R28 为了拿到全身姿态，把底板从 1802 砍到 635 —— **那一刀把具名缺陷清单一起砍掉了**。
**这与 R11 的退化是同一个机制**（为了让构图占主导而删材质词汇），只是这次藏在
"短底板"这个当时被证明有效的改动里，所以当时没有引起注意。

## 本轮改动（单变量）

`BASE_H9_POSE` = `BASE_H8_POSE` 把材质句换成 phase-4 那份缺陷清单，**其余一字不动**：

- shot 1 `propped-bolster`、shot 2 `mat-by-window` 的**姿态文本逐字沿用 R29**
- 用 `assert` 保证 `BASE_H9_POSE == BASE_H8_POSE.replace(材质句)`，
  并断言 R29/R30 的归档 prompt 未被改动
- **刻意不恢复** `BASE_H4_EN` 里的 `a soft blush of warm colour across the cheeks`——
  R27 已证明那句（被前置时）就是"刻意腮红"的来源

底板 776 → 1178 字符；整条 prompt 852 → 1254 字符。
**注意这个量级**：R27 用 1802 字符底板时全身像 0/3 —— R30 正好逼近那个危险长度，
所以本轮同时是对"**姿态前置能否扛住长底板**"的压力测试。

## 关键结论

1. **材质密度不会把镜头拉近**（本轮最干净的结论）：把材质句从 776 加到 1178 字符
   （总量 1254，逼近 R27 失败的 1283），三张**全部守住全身构图**。
   → 与 R21/R29 的推断一致：**"长清单是构图的敌人"里的敌人是「服饰穷举清单」，不是「总长度」，更不是「提到材质」**。
   姿态前置依然是有效的秩序手段。
2. **材质词汇确实是"骨瓷感"的开关**，但 R30 只修回了一半：
   同区域裁切显示 R29 的手是**哑光真人皮**、R30 的手有**釉面光泽**——瓷感确实回来了。
3. **具名缺陷清单没有被执行**：`pinholes` / `orange-peel` / `polishing marks` / `kiln grit`
   在画面上都看不到，换来的反而是**更均匀的表面**——正是 prompt 明令禁止的
   `never a uniform flat surface`。这与 R9「微观釉面未被执行」是同一类现象。
4. **漏了一句关键从句**：`BASE_H9_POSE` 缺 `with crisp specular highlights where the light strikes`
   （`BASE_H4_EN` 有）。这句话很可能是"釉面被看见"的真正开关，而不仅缺陷清单。
   → 直接催生 [R31](r31.md)（补这一句 + 用紧肖像画布做判读板）。
5. **"细腻"的判读需要足够像素**：R30 的方画布是**全身**，脸只有约 180px，
   放大后细节被插值抹平——**判读板的取景和画布一样重要**。R25 当年能做定论，
   靠的是 2048² **紧肖像**。这一条记为本轮的教训。
