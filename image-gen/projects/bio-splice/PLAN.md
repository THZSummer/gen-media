> 已据此重排后面 10 个子主题的期内容：

> 详见 §五 规律 73–78 与各子主题表的「机制预测」列。

## 一、项目定位

把 **A 的器官接到 B 的身上**，用纪实摄影（或显微 / 标本）的写实语言拍出来，像真实存在的物种。

**不限于动物**——植物、真菌、藻类、地衣都可以做底座或供体。分三组：

- **甲组 · 同界跨界（动物 × 动物）**：两种动物之间的器官移植。最成熟的一组，机制结论主要来自这里。
- **乙组 · 跨域拼接（动物 × 植物 × 菌）**：跨越动物/植物/真菌的界。两处钩子来自典籍里「本来就是拼接体」的生物。
- **丙组 · 部件图鉴（同一器官的跨物种轮换）**：固定底座，轮流加同一种器官，做成一册「图鉴」。
  注意：**只能是「空位新增」式的加**，不能是「换掉底座原有的同名器官」——后者是同材质替换，实测只到部分（规律 67）。

## 五、规划所依据的机制（来自已交付 14 期的实测）

| 规律 | 内容 | 对规划的意义 |
|------|------|--------------|
| 56 | 移植成败取决于**底座描述里有没有占位**该部位 | 底座描述要刻意留空目标部位（如蜥蜴底座写 `four stout legs` 而非 `clawed`） |
| 62 | **部位需要载体结构** | 爪/掌必须用有四肢的底座，翅必须用有翼基的底座；规划里四肢件一律不放蛇/鱼身上 |
| 57 | 危险的是**整体名词点名**，不是提到物种 | 移植件一律写 `X 的 <部位>`，绝不写 `X 的身体` |
| 59 | **同区域最多叠两处**，跨区域可叠加 | 每期的部位排布先数区域（头 ≤2），再数总件数 |
| 66 | 占位可以**腾出**（删掉底座描述里的对应词） | 凡「已占位」的部位在表里都标了「需腾出」 |
| 67 | 选题优先级：**空位新增 > 腾出占位 > 同材质替换** | 同材质替换（菌丝覆体、藻层可见、兽皮纹）预期只到部分成立；**再按 90/91 筛一层：空位里也要挑「不同形、高辨识度」的件** |
| 70 | **期内恒定 + 期间各异** | 每期都指定专属「生境·光线·机位·画布」，保证 5 期各有身份 |
| **73** | ❌ **头部件（换头换喙换眼）不可移植**：底座的物种名词**既是占位又是锚** | **所有子主题都不许把「有喙的鱼」「羽冠的鹿」「换脸」写进成品目标**；本表的写法已按此重排 |
| **74** | **部位需要载体结构**（规律 62 的强化） | 爪要四肢、翼要翼基；**植物 / 蛇 / 鱼身上不放四肢件**，无翼基的底座上不放翅 |
| **75** | **小部件（眼）没有可用手法**：腾出眼位也不落地 | 不做以「眼」为卖点的期；图鉴组因此由 `eye-atlas` 改写为 `horn-atlas` |
| **76** | **一轮里只放一个底座** | 同轮对照只对**同底座**的镜头有效；混底座的镜头必须另立一轮补对照，否则客观指标不可用 |
| **77** | **腾出占位不是万能钥匙**：只在底座先验较弱的部位有效 | 头部/脸部不要指望「删掉描述就能腾出」；腾出只对爪、鳞这类外周部位有效 |
| **78** | **规划里判「空位/占位」必须逐字核对底座原文** | D3 兔眼曾被误判成「空位新增」，实际底座写明了 `dark lidless eyes` |
| **79** | **姿态句必须对目标部位保持沉默** | 姿态里提到什么，**底座对照也会长出什么**（R11：姿态写了「两翼张开」→ 对照的猫也长翼，整轮作废） |
| **80** | **呈现层不是中性的**：机位/画幅会改变移植结果，光线决定细部件能否被看见 | 生境/时间可换，**机位与主体在画面里的相对大小不能随便换**；细线部件要暗背景+侧光（R10/R14 猫尾、R12 胡须） |
| **81** | **空间关系从句失效，改名词短语** | `X wrapped around Y` 是空操作，`X coils around Y` 才落地——**部件与底座之间的关系也要写直白**（turtle-snake 的 N3 缠体） |
| **82** | **「该成却没成」时先怀疑写法，再怀疑占位** | N3 按机制排在「最容易」档却 0% 落地，只改句子结构就成了 |
| **83** | **腾出占位能否成立，取决于底座对该部位的依赖程度** | 龟的颈/尾删掉不伤底座 → 完整成立；猫掌、蛇鳞、鱼鳍删掉就伤可信度 → 只到部分或 0%（与 87 同一件事的两面） |
| **84** | **多 take 是低成本的可重复性检验** | 同一呈现换 seed 出 2–3 张，都成立才敢说「这个部件稳」（turtle-snake 期 01/02） |
| **85** | ⚠️ **生境是硬约束**：移植件与场景语义冲突时，模型**保场景、丢部件** | **先选兼容生境，再谈写法与占位**——这条排在写法纪律之前。证据：同一底座同一句话，水下 0% / 离水 100%（fish-bird） |
| **86** | **场景兼容性按区域判断** | 同一画面里，露出来的部分能长件、泡在水里的部分不能（fish-bird 期 02） |
| **87** | **典范结构腾不出占位** | 鱼鳍／猫掌／蛇鳞／鹿颈鹿腿删掉描述也会被模型补回来；与龟的颈尾（删掉不伤底座）构成对照（与 89 是同一现象的两面） |
| **88** | **「唯一可用部件」也能撑起一个子主题** | 把**呈现层的自变量**当期间差异（fish-bird 的出水阶段），不必强求每期换一个部件 |
| **89** | **典范结构：改得动形状，改不动材质** | 鹿颈/鹿腿、鱼鳍、猫掌、蛇鳞都属此类；**腾出占位对它们既不加分也不减分**（deer-crane R2 vs R3 对照） |
| **90** | **空位是必要条件，不是充分条件** | 还要看供体件的**辨识度**：鹿尾是唯一真空位，鹤尾羽命中率也只有 1/4（4 个 seed 成 1 个） |
| **91** | **供体优先级再收窄：不同形 > 同形** | 角/耳/羽扇/缠体一眼可辨；颈换颈、腿换腿、鳞换鳞只会得到「瘦长/变形」的同一只动物 |
| **92** | 🎯 **底座形态自由度决定移植难度**（总判据） | 底座越定型（鹿/鱼）→ 移植越难；底座越像原料（菌丝体）→ 越容易。**83/87/90/91 都是它的推论** |
| **93** | **尺度也是呈现层的一部分** | 微距题材要换掉整套取景句与摄影层（`macro photograph, focus-stacked`），CN/摄影模板不能跨尺度复用 |
| **94** | **呈现可以救弱期** | 部件「看不见」（内部结构/同材质）时，先改呈现（剖面、掀开、打光）：藻层期因此从最难变成最好（5.00 ×2） |
| **95** | **对照已经把一半做完了就要扣分** | 底座自带某形态时，移植件的边际贡献如实评估（枝状地衣 4.55 而非 5.00） |
| **96** | 🎯 **可腾出的是「属性」，腾不出的是「结构」** | 体表质感/颜色/纹理删得掉（虫草 MY1：腾出版 A=4 vs 占用版 A=3）；器官肢体删不掉（89/87）。**96 与 92 互补**：92 看底座整体多定型，96 看你要腾的那一处是结构还是属性 |
| **97** | **「从体表长出的件」不需要承载结构** | 子座只要有「体表」这个面就能长（虫草 6 张 5.00）；而爪必须有四肢。**挑件时先问：它需要什么承载面？** |
| **98** | **换呈现媒介 = 收官期的低成本升级** | 生态照 → 标本照，部件一字不改，交付物身份从「拍到的」变成「收藏的」（虫草期 05） |
| **99** | 🎯 **判据落在「落点」，不是「整体」** | 捕蝇草整体很定型（92 不利）却三件全成，因为落点（边缘/叶面/内腔）都不是典范结构。**92 是整体视角，99 是局部视角** |
| **100** | **「腾出占位」的第三类：边界附属物 ≈ 属性** | 结构（器官肢体）腾不出（87/89）、属性（质感颜色）腾得出（96）、**边界附属物（缘齿/缘毛/锯齿）也腾得出** |
| **101** | ⚠️（假设·未验证）**跨界件的「接缝」决定可信度** | 植物上单长一只眼球容易读作「贴上去」；补「窝/睑/接缝」可能提高 C 分——留给后续验证 |
| **102** | **换底座要重新验命中率** | 同一写法在玉兰上 5/5、在百合上 1/2（flower-bird 期 04）→「写法验证过」≠「到处都能成」 |
| **103** | **写法要连着落点一起看** | 「覆盖式」在 cordyceps 的虫体上（属性）成立，在花的花瓣环（结构）上完全失效 |
| **104** | **机制限制常常给出更好的构图** | 换不掉花瓣 → 落点退到花心 → 反而更像「花鸟」。**限制不是损失，是设计约束** |
| **105** | 🎯 **两条独立门槛：落点是不是典范结构 + 这件需要什么承载面** | 兽足两条都不过（根系是结构 + 足需要关节）→ 0%；兽角两条都过 → 5.00。**选件时两个问题都要问** |
| **106** | **换底座是否降命中率，取决于落点性质** | 属性替换与空面新增对底座形态依赖低（老树→枯立木仍成）；需要几何配合的落点敏感（玉兰→百合 5/5→1/2） |
| **107** | 🎯 **供体的语义类别必须与落点的功能匹配** | 「背上加一对翅」：昆虫膜翅/蝙蝠皮翼/飞鱼鳍（自带飞行语义）全成；**鱼胸鳍 0%、种子翅部分**——形状像不够，**语义要对**（规律 85 的部件-落点版） |
| **108** | **图鉴类子主题要有「基准部分」** | 第 1 部分不放移植件，既是第一页也是后四部分的参照系（wing-atlas 与 horn-atlas 同构） |
| **109** | 🎯 **门槛可以主动凑齐** | 把「落点空面（99）+ 不需承载结构（97）+ 不需腾占位（96）+ 语义匹配（107）」一次性对齐 → **零失败**（horn-atlas 六种角全成） |
| **110** | **形态可以补偿语义的小偏差** | 独角鲸的长牙解剖上是牙不是角，但「一支向上的螺旋」的形态被模型接受了 |
