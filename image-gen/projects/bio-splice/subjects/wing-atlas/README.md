## 一、概念：把「翅」当成一个**可加的器官**

**固定一只鸟（保留它自己的翅膀），在背上再加一对别人的翅。**
本册是全项目**唯一不换底座**的子主题——所以它是一本真正的「图鉴」：
同一个体、同一机位规格，只换背上那对翅。

- **底座 ＝ 中型鸟**（保留自身羽翼）
- 供体 ＝ 四种「第二对翅」：昆虫膜翅 / 蝙蝠皮翼 / 飞鱼长鳍 / 鹤的白翼

> 原计划是「把鸟翼**换成**别的翅」（同材质替换，规律 67 第 3 档），
> 已按规律 99 改成「**在背上再加一对**」（落点＝背部空面）——这是本册能成立的前提。

## 三、规律 107：**供体的语义类别必须与落点的功能匹配**

同一个落点（背部）、同一套句式、同一个 seed，**只换供体**：

| 供体 | 语义 | 结果 |
|------|------|------|
| 昆虫膜翅 / 蝙蝠皮翼 | 会飞的翅 | ✅ |
| **飞鱼**长鳍 | 鳍，但**自带「飞」** | ✅ |
| 鱼胸鳍 | 鳍，与飞无关 | ❌ |
| 枫树种子翅 | 植物种子 | ⚠️ |

> **光有「像翅的形状」不够**（鱼鳍、翅果的形状也像翅），**必须具备「能飞」的语义**。
> 这是规律 85（生境语义相容）在**部件-落点**层面的版本。

## 四、设计要点：**基准部分**（规律 108）

第一部分**不放移植件**，只放统一底座的三个 take：
它既是"第一页图鉴"，也是后四部分的**参照系**。
→ 图鉴类子主题（本册与 `horn-atlas`）都采用这个结构。

## 五、自评

| 项 | 数 |
|----|----|
| 轮次 | 8 轮（R1 基准 / R2–R5 四种翅 / R6 语义追问 / R7–R8 定稿） |
| 生成张数 | 25 张（zimage，1024² / 1280×1024，steps 12） |
| 成品 | **11 张 / 5 部分** |
| 平均分 | **5.00**（全部首选） |
| 不合格 | 2 张（鱼胸鳍 ×2）＋ 3 张部分（种子翅） |

**一句话**：本册把「落点空面 + 不同形 + 高辨识度」三条有利条件一次用满，
唯一的坑是**语义**——这也是全项目第一次把"语义类别"和"形状相似"分开来看。
