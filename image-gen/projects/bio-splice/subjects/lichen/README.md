## 一、概念：自然界**已经拼好了**的那一个

**地衣本身就是一种拼接生物**——真菌菌丝 + 藻/蓝细菌的共生体。
这是「生物拼接」**最本体的例子**：不是我们把 A 接到 B 上，
而是**把「已经拼好的共生体」呈现出来**。

- **底座 ＝ 真菌菌丝体**（刻意不写形态、不写颜色，都留给移植件）
- 供体 ＝ 形态件（壳状 CR1 / 叶状 FL1 / 枝状 FR1）+ 藻件（绿色细胞 AL1 / 藻丝 AL2）

这也是乙组（跨域拼接）的第一个子主题——**跨越的不是物种，是界**。

## 三、核心发现：**底座越没有固定形状，移植件越容易落地**（规律 92）

| 底座 | 先验强度 | 移植件结果 |
|------|----------|------------|
| 鹿（deer-crane） | 强：颈/腿是**典范结构** | 只能改形状，改不动材质（4.25） |
| 鱼（fish-bird） | 强：鳍是典范结构 | 0% |
| 蛇 / 龟 / 蜥（甲组） | 中：体形固定，但部件位可腾 | 空位件完整成立 |
| **真菌菌丝体（本子主题）** | **极弱：一团没有固定形状的菌丝** | **五个部件全部成立** |

> **规律 92**：移植难度与**底座的形态自由度**强相关。
> 底座越像一个「已经定型的物种」，移植件越难；底座越像「一团原料」（菌丝体、黏菌、珊瑚），
> 移植件越容易——模型没有「它应该长什么样」的先验来抵抗。
>
> 这条把 83/87（典范结构）、90（空位非充分）、91（不同形优先）统一成一个更简单的判据。

## 四、呈现层的两点新做法

1. **尺度也是呈现层的一部分**：这是几厘米的生物，取景句换成「微距特写」、
   摄影层换成 `macro photograph, focus-stacked`，不复用动物子主题的「全身像 + 600mm 长焦」。
2. **「拟剖面」把最难看的东西变成主体**：期 04「藻层可见」本来是最难的一期
   （藻层在地衣内部），用「表层被掀开、露出内部结构」的呈现后，
   绿球与藻丝直接成了画面主角——**呈现可以救一个机制上很弱的期**。

## 五、自评

| 项 | 数 |
|----|----|
| 轮次 | 5 轮（一期一轮，每轮都带同轮底座对照） |
| 生成张数 | 16 张（zimage，1024² / 1280×1024 / 1024×1280，steps 12） |
| 成品 | **11 张 / 5 期** |
| 平均分 | **4.87**（最低 4.55，最高 5.00） |
| 不合格 | 0 张 |

**一句话**：这是目前**最省力、成品率最高**的子主题——
因为「拼接」在这里本来就是生物自己的事，模型只需要把菌丝与藻画在一起。
**乙组剩下的四个子主题都应当从中受益**，不过它们各有各的难点：
`cordyceps` 是「菌覆虫」（同材质替换），`flytrap-fang` 要跨到动物器官，
`tree-beast` 的底座是树（形态自由度中等）。
