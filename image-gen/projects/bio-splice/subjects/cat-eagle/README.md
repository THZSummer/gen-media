## 一、概念

**「猫头鹰」这个词本身就是一次动物拼接**（猫 + 头 + 鹰）。所以这个子主题不造怪物，
而是把词面直译成一个 `{猫, 鹰} × {猫, 鹰}` 的**头身拼接矩阵**：

|              | 猫的身体 | 鹰的身体 |
|--------------|----------|----------|
| **猫的头**   | 猫（**退化角**：对照组） | **猫头鹰**（词面直译）✅ |
| **鹰的头**   | **鹰头猫**（反向拼接）❌ | 鹰（**退化角**：对照组） |

两个退化角是**对照组**：如果纯猫、纯鹰和拼接体在同一套摄影语言下"一样真"，
就证明拼接感来自**头身错配本身**，而不是画风。

## 二、结论（两期之后回看）

### ✅ 猫的头 + 鹰的身体 —— 成立（第一期成品）

一次就成。猫头（小型、通用、圆形部件）搁在鹰身上不与鹰的体型方案冲突，
同 seed 下还**复用了鹰对照的构图**，"同一只鹰换了个猫头"一眼可读。

### ❌ 鹰的头 + 猫的身体 —— 在 Z-Image-Turbo 上做不到（暂不成期）

四条路全部试过，全部失败：

| 路线 | 结果 |
|---|---|
| 头在前 | **纯鹰**（无任何猫元素） |
| 身在前 | 完整猫 + 追加鹰头 → **双头** |
| 给身体去名（只写部件） | 退回**纯鹰**（`cat` 是承重词） |
| 名字绑部件 / 正向单头计数 / 去并列结构 | 仍**双头** |

> **后续修正（R6/R7）**：危险的不是"提到鹰"，而是**把动物当整体名词点名**。
> `eagle wings`（部位修饰语）安全，`an eagle's body`（整体名词）危险 ——
> 因此**部位拆分是这条阻塞的绕法**。见 [r03.md](rounds/r03.md) §三。

**机制**（由四轮单变量 + 同 seed 对照定位）：

1. **被点名的动物会整体渲染**：头位 → 只给一个头；身位 → 给一整只（含它自己的头）
2. **正向排除句（`no X`）与正向计数（`exactly one X`）都不被执行** ——
   Z-Image-Turbo 用 `ConditioningZeroOut`，没有负向提示词
3. **强势物种的整体先验会吃掉弱物种的身体**：鹰（翅膀/爪/羽是有辨识度的整体方案）vs 猫（通用四足）

> 要成立必须换工具：**Qwen-Image 的真负向**（排除 `two heads, cat head, wings, talons`），
> 或 **ControlNet 结构锁**（用纯猫对照当控制图锁住身体）。
> 完整证据与审计方法见 [`rounds/r02.md`](rounds/r02.md)。

> **period-06（鹰头猫）正式作废**：它需要的正是「换头」，而换头在 zimage 上是**双向死局**
> （规律 73：留着底座物种名词 → 头部件 0% 落地；删掉它 → 供体接管整只动物）。
> 这条结论后来由 `dragon-nines` 的 D2 驼头 / D3 兔眼独立复现（R8/R9），
> 所以不再是「阻塞、等换引擎」，而是**这个方向不做**。

> 每期都附**打分复核报告**（`rounds/rNN-review.md`）：A 移植到位 / B 底座完整 / C 解剖可信 /
> D 摄影统一 / E 概念可读，加权总分 + 门槛判定。**只有 ✅ 才能进期目录。**

> 期的门槛是**全部为成品**。没有成品就不建期目录。
> 部位编号见[部位表](parts.md)；组合顺序按难度：强底座+小件 → 弱底座+强局部件 → 多部位。

## 三之二、呈现是踩出来的（R10–R17）

期 01–05 原本共用同一套「晨雾秋日草甸 · 阴天柔光 · 平视 600mm · 方」，
五期读起来像「同一张照片换了配件」。补呈现层的四轮（R10–R13）**连踩三个坑**，
每一坑都成了后面的规矩：

| 坑 | 现象 | 规矩 |
|----|------|------|
| **机位/画幅改变移植结果** | 同一句猫尾：平视全身像**成立**；低机位 85mm 竖幅**多画出一只完整的猫** | 换机位/画幅必须复核部位是否仍落地（80） |
| **姿态句污染底座对照** | 姿态写成「它把两翼张开到最大」→ **对照的猫也长了鹰翼**，客观指标作废 | 姿态句必须对目标部位保持沉默（79） |
| **光线决定细部件生死** | 猫胡须：正午硬光下**完全不可读**；暗背景单侧光下清晰成立 | 选光要冲着部件的材质去（80） |

> 三次修正（R14–R17）都只动呈现层、底座与移植件一字不改，
> 所以前面所有机制结论照旧成立——**这正是"期内恒定"的价值**：改呈现时能一眼看出变量。

## 三之三、子主题总结（全项目收官后回看）

本册是**全项目的第一个子主题**，也是整套机制结论的**源头**——
后面 11 册用的规律，有一半是在这里第一次踩出来的。

### 1. 实测账

| 项 | 数 |
|----|----|
| 轮次 | 17 轮（R1–R5 鹰头猫方向的单变量诊断 / R6–R9 部位拆分 / R10–R17 呈现轮） |
| 成品 | **14 张 / 5 期**（+ 6 张对照） |
| 均分 | **4.35**——全项目偏低，因为期 01–05 里有三期的部件只到"部分成立" |
| 不合格 | 若干（鹰头猫方向的失败轮、以及 R10/R14 的"多画一只猫"） |

### 2. 本册贡献的机制结论（后来被反复引用）

| 规律 | 内容 | 后来在哪里被再次验证 |
|------|------|----------------------|
| **57** | 危险的是**整体名词点名**（`X 的身体`），不是提到物种 | dragon-nines 的 D2 驼头（换头双向死局） |
| **59** | **同区域最多叠两处**，跨区域可叠加 | dragon-nines R4 的四件叠加、turtle-snake 的玄武 |
| **62** | **部位需要载体结构**（蛇没有四肢 → 鹰爪无处可长） | fish-bird 的鱼鳍、tree-beast 的兽足 |
| **67** | 选题优先级：空位新增 > 腾出占位 > 同材质替换 | 全项目所有子主题的选题 |
| **79** | **姿态句必须对目标部位保持沉默**（否则对照也会长出该部件） | 所有后续子主题的守卫 assert |
| **80** | **呈现层不是中性的**（机位/画幅会改变移植结果） | turtle-snake 期 02 改为平视、fish-bird 的重排 |

### 3. 本册的三条自我批评

1. **期 01–05 的呈现是事后补的**：五期原本共用一套秋日草甸，后来才发现"期内恒定"被错用到了跨期上
   （规律 70 就是在这里立的）。原始五期的成品虽然保留，但呈现是重做的。
2. **鹰头猫方向（period-06）走错了 5 轮**：直到 dragon-nines 用 D2/D3 独立复现，
   才敢判定"换头不可行"（规律 73）——**当时应该先做一次最小探针，而不是连做四轮单变量**。
3. **猫掌失败的原因一开始归错了**：先归因到"负向提示词缺失"，后来才定位到"底座占位 + 无负向"
   两个原因叠加（规律 56/58）。

### 4. 一句话

**如果没有这一册踩的坑，就没有后面 11 册的判据表**——
它是全项目最"贵"的一册（17 轮换 14 张），也是最值的一册。
