## 一、概念：古人的**部件表**

传统**画龙口诀「三停九似」本身就是一张九项部位表**：

> 角似鹿、头似驼、眼似兔、项似蛇、腹似蜃、鳞似鱼、爪似鹰、掌似虎、耳似牛

（王符、罗愿《尔雅翼》、李时珍《本草纲目》等均有记述；「三停九似」之说见《医暇卮言》等。
参见[「角似鹿、项似蛇……找找『真龙』形象」](https://baijiahao.baidu.com/s?id=1790105790609233561)）

所以这个子主题不是我们发明拼接，而是**执行一张古人已经写好的部件表**——
与 cat-eagle 子主题（拆「猫头鹰」这一个词）同构，但供体从 1 个动物变成 8 个。

**底座 = 蛇**（「项似蛇」即身体主轴）。

## 二、为什么这个子主题机制上特别合适

本仓 r02–r04 定位的规律，正好都指向"部件表"这条路：

| 规律 | 对本子主题的含义 |
|------|------------------|
| 57 危险的是**整体名词点名**，不是提到物种 | 移植件一律写成 `X 的 <部位>`，绝不写 `X 的身体` |
| 56 移植成败取决于**底座有没有占位** | 蛇**没有**角、耳、爪、掌 → 全是空位，最容易成 |
| 56 的补充（本轮新增） | 但还要看**该部位所需的载体结构是否存在**（见下） |
| 59 同区域最多叠两处 | 头部件（角/耳/眼/头）要分期或错开 |

## 三、核心发现：**部位需要载体结构**

### 第一期：蛇底座 + 鹿角 —— 成立

「有角的蛇」**一次就成**：分叉鹿角从颅骨自然长出，一眼读作**龙**。加牛耳也成立。

### 但「爪似鹰」在蛇身上**完全失败**

蛇**没有四肢**——爪不是被底座描述覆盖（规律 56 的那种失败），而是**无处可长**。

> **规律补充**：规律 56 只说了"底座没占位就能移植"，但那默认**该部位所需的载体结构存在**。
> 蛇没有前肢 → 鹰爪无法落地。**底座的解剖结构必须能承载移植件。**

### 第二期：换成有四肢的蜥蜴底座 —— 部分成立

换 `蜥蜴`（有四肢、同样是蛇形躯干）后，爪**部分成立**：爪形从基准的**短钝蜥蜴爪**
变为**长而弯、抬起作抓握状的猛禽式爪**；但没到完整的鹰爪（足部仍是深色鳞质，
不是鹰的黄色鳞状跗跖）。虎掌 D8 未成立。

> 这与中国龙的形象吻合：**龙是四足蛇身**——「项似蛇」取蛇，「四足」必须另找底座。

## 四、期内恒定，期间各异

| 范围 | 要求 | 为什么 |
|------|------|--------|
| **期内** | 生境 / 光线 / 机位 / 画布**必须恒定** | 保证该期"移植 vs 底座对照"可比（同 seed 同骨架，唯一变量是移植件） |
| **期间** | 这四项**应当各异** | 让每期有自己的身份，否则整组读成"同一张图换了配件" |

系列恒定层只留两条（保证两个子主题还能并置成一套）：**CN 取景句** + **写实野生动物摄影的底子**。

> 这条是踩出来的：R1–R4 四期把"层恒定"用到了跨期上，导致四期看起来只有移植件不同。
> 改成"期间各异"、并**按主体选机位**（期 02 冲爪、期 03 冲鳞）之后，
> 两期原本"部分成立且难判读"的部位也变成一眼可辨。

## 五、期

**每期有自己的身份**：底座与移植部位决定"是什么"，**生境 / 光线 / 机位 / 画布**决定"看起来什么样"。
后者按主体挑（期 02 的机位冲着爪、期 03 的冲着鳞），细则见 [`rounds/dn-r5-r7.md`](rounds/dn-r5-r7.md)。

**五期齐了**（10 张成品）。九似九项里：**完整成立 2 项**（角 D1、耳 D9）、
**部分成立 3 项**（鳞 D6、爪 D7、项 D4 即底座本身）、**未成立 3 项**（掌 D8、头 D2、眼 D3）、
**未执行 1 项**（腹 D5 蜃——神话生物，需先定视觉代理）。

> 「腹似蜃」的蜃无真实对应动物，**暂不执行**；先定视觉代理
> （候选：巨蚌的棱纹腹面 / 蜃景般的虹彩腹鳞）再开期。

## 六、子主题总结（收官后自评）

### 1. 九似这张表，能执行的只有"空位 + 有载体"的那一类

| 类型 | 部位 | 结果 | 机制 |
|------|------|------|------|
| **空位新增**（底座没有该部件） | D1 角、D9 耳 | ✅ 完整成立（5.00） | 最容易，一次就成 |
| **腾出占位**（先删掉底座里的对应描述） | D6 鳞、D7 爪 | ⚠️ 部分成立 | 有效，但只改形不改材质 |
| **同材质替换** | D6 鳞（换鳞） | ⚠️ 部分且难判读 | 概念可读性最低 |
| **头部件**（物种身份所在） | D2 头、D3 眼 | ❌ 双向死局 | 见下 |
| **无载体结构** | D7 爪（蛇底座上） | ❌ 0% 出现 | 换底座即解决 |

### 2. 本子主题最重要的两条否定结论

**（1）头部件换不掉——它是物种身份本身。**
腾出占位（删掉头形与眼的描述）→ 驼头 0% 出现，画面反而**更蛇**（模型补出颈褶）；
删掉底座的物种名词（`snake`）→ **整只骆驼被拖出来**，底座被毁。
**底座物种名词既是"占位"又是"锚"**，删了它供体就接管整个个体。

> 推论（已回写 PLAN）：**换头 / 换喙 / 换脸这一类不要写进任何子主题的成品目标。**

**（2）"腾出占位"不是万能钥匙。**
它只在**底座先验较弱**的部位有效（爪、鳞都有可见变化）；
遇到头部这种先验极强的部位，腾出来的空位会被模型自己的物种先验填回去。

### 3. 本子主题踩到的共性问题（已回写 PLAN §五）

| 问题 | 后果 | 修法 |
|------|------|------|
| 把"层恒定"用到跨期 | 四期读成"同一张图换配件" | 期内恒定 + **期间各异**（规律 70） |
| 规划里凭直觉判"空位/占位" | D3 兔眼被误判成"空位新增、易成"，实际底座写明了眼 | 排期前**逐字核对底座原文**再判占位 |
| 一轮里混多个底座 | 同轮对照只对同底座的镜头有效，另几张客观指标不可用 | **一轮一个底座**（规律 76） |
| 规划里把"头部件"当普通部位 | 期 05 原计划（驼头+兔眼）两件皆否，收官期差点交白卷 | 头部件一律降级为"预期失败、不作成品目标" |
| 客观区域差被当成成功判据 | R8 区域差 11.6–15.9 远高于阈值，但部位一件没落地 | 区域差只作**单向报警**：没变 → 肯定没落地；变了 → 什么都不说明 |
