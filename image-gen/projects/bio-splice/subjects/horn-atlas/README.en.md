## 1. Concept: fix one **hornless horse** and grow five kinds of horn on it in turn

Treat "horns" as an **addable organ** and make an atlas of it —
the same individual, the same meadow, the same focal length, swapping only the single horn on the top of the forehead / the bridge of the nose.

- **Base = a standard horse** (**originally hornless** = an empty surface)
- Donors = five kinds of horn: deer / cattle / sheep / rhinoceros / narwhal

> This volume was originally planned as `eye-atlas` (eye · atlas) and was rewritten per rules 73/75:
> the eye is a **small part + same-material substitution + head-part family**, and all three step on mines found in testing.

## 3. Why zero failures: **all five thresholds passed**

| Threshold | This volume's situation |
|------|-----------|
| The landing site is an empty surface (rule 99) | the horse **is originally hornless**; the top of the forehead / the nose bridge are empty surfaces |
| No bearing structure needed (rule 97) | the horn grows directly out of the frontal/nasal bone surface |
| No need to vacate space (rule 96) | there is no "horn" in the base description |
| Different shapes + high recognisability (rules 91/90) | deer antlers / cattle horns / sheep horns / tusk / rhino horn are all different |
| **Semantic category matches (rule 107)** | the five donors **are horns in themselves** |

→ **This is an "all conditions satisfied" validation of 92/96/97/99/105/107**:
gather these thresholds **deliberately** and you get a sub-theme with zero failures (rule 109).

## 4. The one small deviation: a tusk is not a horn

**The narwhal's tusk** is anatomically a "tooth", not a "horn" (the semantics are slightly off), but its form is a **long spiralling horn** —
and it holds up completely in testing. → **When form and semantics both hold, form carries a small semantic deviation through** (rule 110).

## 5. Design focus: isomorphic with wing-atlas

The two atlas volumes share one skeleton (rule 108):
**part 1 = baseline, parts 2–5 = four candidate organs**;
the baseline part is both the first page and the frame of reference for the last four (which is why it has no control shot).
