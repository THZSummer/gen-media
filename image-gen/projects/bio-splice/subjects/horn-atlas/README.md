# 子主题：角 · 图鉴

> **全子主题总览图**：[`sheet.jpg`](sheet.jpg) —— 每期一行，把该期成品拼在一起（`bash make_sheet.sh subject horn-atlas` 可复现）

## 一、概念：固定一匹**无角的马**，轮流长五种角

把「角」当成一个**可加的器官**做成一册图鉴——
同一个体、同一片草场、同一焦段，只换额顶/鼻梁上的那一支角。

- **底座 ＝ 一匹标准马**（**本来无角** ＝ 空面）
- 供体 ＝ 五种角：鹿 / 牛 / 羊 / 犀 / 独角鲸

> 本册原计划是 `eye-atlas`（眼·图鉴），已按规律 73/75 改写：
> 眼是**小部件 + 同材质替换 + 头部件族**，三条都踩在实测的雷上。

## 二、结果：**六种角零失败**（全项目唯一没有否定结论的子主题）

| 部分 | 供体 | 呈现 | 成品 | 评分 |
|------|------|------|------|------|
| [period-01](period-01/README.md) | **无角基准**（无移植件） | 晨雾草场 · 柔光 · 平视 · 方 | 3 | **5.00 ×3** |
| [period-02](period-02/README.md) | 鹿角 | 同上 · 侧逆光 | 2 | **5.00 ×2** |
| [period-03](period-03/README.md) | 牛角 | 同上 · 顶光 | 2 | **5.00 ×2** |
| [period-04](period-04/README.md) | 羊角 | 同上 · 侧逆光 | 2 | **5.00 ×2** |
| [period-05](period-05/README.md) | 独角鲸长牙 + 犀角（收官） | 霜晨草原 · 侧逆光 · 贴面特写 · 竖 | 2 | **5.00 ×2** |

## 三、为什么零失败：**五条门槛全过**

| 门槛 | 本册的情况 |
|------|-----------|
| 落点是空面（规律 99） | 马**本来无角**，额顶/鼻梁是空面 |
| 不需要承载结构（规律 97） | 角从额骨/鼻骨表面直接生出 |
| 不需要腾占位（规律 96） | 底座描述里没有"角" |
| 不同形 + 高辨识度（规律 91/90） | 鹿角/牛角/羊角/长牙/犀角各不相同 |
| **语义类别匹配（规律 107）** | 五种供体**本身就是角** |

→ **这是对 92/96/97/99/105/107 的一次「全条件满足」验证**：
把这些门槛**主动凑齐**，就能得到零失败的子主题（规律 109）。

## 四、唯一的小偏差：长牙不是角

**独角鲸的长牙**解剖上是"牙"不是"角"（语义略偏），但形态是一支**螺旋向上的长角**——
实测完全成立。→ **形态与语义同时成立时，语义的小偏差会被形态带过去**（规律 110）。

## 五、设计要点：与 wing-atlas 同构

两册图鉴共用同一个骨架（规律 108）：
**第 1 部分 = 基准，第 2–5 部分 = 四种候选器官**；
基准部分既是第一页，也是后四部分的参照系（因此它没有对照镜头）。

## 六、自评

| 项 | 数 |
|----|----|
| 轮次 | 5 轮（一部分一轮，每轮都带同轮底座对照，基准轮除外） |
| 生成张数 | 15 张（zimage，1024² / 1024×1280，steps 12） |
| 成品 | **11 张 / 5 部分** |
| 平均分 | **5.00**（全部首选） |
| 不合格 | **0 张** |

**一句话**：本册是全项目的**收官之作**，也是唯一一个"零失败"的子主题——
它证明了前面 100 多条机制结论**不是马后炮**：只要按它们选题，就能一次做对。
