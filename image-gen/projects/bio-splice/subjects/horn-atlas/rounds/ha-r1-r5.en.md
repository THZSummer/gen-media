## 2. Why zero failures: all five thresholds passed

| Threshold | This volume's situation |
|------|-----------|
| The landing site is an empty surface (99) | the horse **has no horns to begin with**, so the top of the forehead / the nasal bridge is an empty surface |
| No bearing structure needed (97) | the horns grow directly from the surface of the frontal / nasal bone |
| No placeholder to free (96) | there is no "horn" in the base description |
| Different shapes + high recognizability (91/90) | antlers / ox horns / ram horns / tusk / rhino horn all differ |
| **Semantic category match (107)** | the five donors **are horns themselves** |

→ **This is an "all conditions satisfied" validation of 92/96/97/99/105/107**:
by deliberately lining up these thresholds, one gets a sub-theme with zero failures.

## 3. The only small deviation

**The narwhal's tusk** is anatomically a "tooth", not a "horn" (a slight semantic deviation), but its form is **a single spiraling long horn**—
in practice it holds completely. → **When form and semantics both hold, a small semantic deviation is carried along by the form.**
