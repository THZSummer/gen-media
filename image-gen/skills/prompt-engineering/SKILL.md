# 提示词工程（Prompt Engineering）

**用途**：把"想要什么"翻译成模型能稳定执行的描述；让出图**可控、可复现、可协作**。

## 何时用

- 出图不可控、风格漂移、多张图之间对不上
- 要为项目沉淀可复用的 prompt 模板

## 四要素结构（缺一项多一分随机）

| 要素 | 回答 | 示例 |
|------|------|------|
| **主体** | 谁 / 什么 + 外观特征 | 现代舞者，女性，浅青水墨渐变纱裙，发髻简洁 |
| **场景** | 在哪 + 什么光 | 淡雅茶室，木质地板、纸屏，暖色侧光 |
| **风格** | 什么色调 / 画风 | 青绿水墨，留白，氛围感，胶片颗粒 |
| **构图** | 景别 + 画面重点 | 中景，人物居中，茶烟从画面右下升腾 |

**增强项（按需叠加）**：镜头语言（85mm 人像、浅景深、俯拍/平视）、光比时段（黄金时刻、逆光轮廓）、质感词（丝绸、哑光金属、皮肤纹理）、负面约束（不要文字、背景不要杂物）。

## 模板库

**通用出图**

```
<主体：谁+外观特征>，<场景：地点+光线>，<风格：色调+画风>，<构图：景别+重点>，<增强：镜头/质感>
```

**分镜图（接 video-gen I2V）**

```
<通用视觉锚点>，<该镜关键姿态的静态定格>，<场景与光>，<色调风格>，<景别>
```

**角色设定**

```
<年龄/性别/身份>，<发型发色>，<服装配色与材质>，<标志性配饰>，<体态气质>，<背景：纯色/简洁>，全身/半身，<视角>
```

**编辑指令（pro）**

```
<保持不变的部分，显式强调>，<要改的部分，具体描述>，<光线/色调一致要求>
```

**多图参考（pro）**

```
把@图像1的<主体>放入@图像2的<场景>，<主体特征>保持完全不变，<光线/比例>与场景一致
```

## 迭代策略

1. **先粗后细**：第一轮只定主体+场景+风格，构图满意后再补细节
2. **单变量迭代**：每次只改一个维度（先调光线，再调构图），否则无法归因
3. **锁定复现**：定稿 prompt + `--seed` 一起记录，才能复现同一张图
4. **沉淀模板**：跑通的 prompt 抽成模板，写进项目 README
5. **服务端优化慎用**：`--optimize-prompt` 会改写 prompt，追求可控时关掉

## 踩坑点

- ⚠️ **空泛词无效**："漂亮""高级感"几乎不产生稳定差异，换具体描述
- ⚠️ **要素缺失 = 随机**：没写构图就随机景别，没写光线就随机打光
- ⚠️ **中文长句堆砌**：逗号分句、一项一短语，比长句更易被正确解析
- ⚠️ **风格词打架**："水墨" + "写实摄影" + "赛博" 互相稀释，一次定一个主风格
- ⚠️ **编辑指令过载**：一次改太多，主体一致性崩溃；拆多轮
- ⚠️ **@引用错位**：`@图像N` 按 `--input` 顺序，顺序变了 prompt 就错了

## 检查清单

- [ ] prompt 覆盖主体 / 场景 / 风格 / 构图四要素
- [ ] 没有空泛形容词替代具体描述
- [ ] 一次只保留一个主风格
- [ ] 编辑/多图参考指令里明确了「保持不变」的部分
- [ ] `@图像N` 与 `--input` 顺序一致
- [ ] 定稿 prompt + seed 已记录，可复现
- [ ] 可复用 prompt 已沉淀为模板
